# Python 开关级 EMT 模型（HPT）— 状态

目标：用 Python 建立与 Simulink 开关级模型**功能一致**的电磁暂态（EMT）仿真，作为
**精度优先的验证器**（接受慢、不用于 RL 训练）。方法：EMTP 节点法 + 梯形伴随模型 + 逐步
开关/二极管一致性迭代。

## 关键结论（截至当前）

- **内核与物理是对的**：内核在 4 类有解析解/已知行为的电路上通过；并联桥在**绕过保护逻辑
  直接给固定调制**时，`m↑⇒Vdc↑` 单调，且 m=0.70→751V 与 Simulink 同区间——证明开关桥+
  Δ-Yg 变压器+直流的能量传递建模正确。
- **闭环 m_sh→Vdc 曲线偏平**的原因是**保护地板 + SAC直接调制 命令包装**（与 Simulink 同源逻辑），
  以及 50–60ms 短窗口的暂态未稳——不是物理错误。Simulink 的 750/913 也是 50ms 暂态读数。
- 因此"消除 ODE 不准"的路线**在物理层面已走通**；要让闭环数值与 Simulink **逐点对齐**，
  还需：变压器参数精标、控制时序/窗口对齐、加串联桥与故障。
