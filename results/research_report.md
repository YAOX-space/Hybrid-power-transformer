## 1. 项目背景

### 1.1 分布式能源接入带来的问题

随着光伏、风电等分布式能源大规模并网，配电网面临三类核心问题：

| 问题 | 描述 | 危害 |
|------|------|------|
| **电压越限** | PV注入功率导致馈线末端电压超出±10%范围 | 频繁跳闸、设备损坏 |
| **电压波动** | 光照/负荷瞬变引起V₂在百毫秒内大幅摆动 | 敏感负荷故障（CT/手术设备THD<6%） |
| **故障穿越失败** | IGBT开路/短路/电容退化导致变换器失去控制能力 | 停电、连锁反应 |

传统配电变压器依赖有载调压开关（LTC）调节电压，动作时间数秒至分钟，无法满足<5 ms的快速响应要求。

### 1.2 混合配电变压器（HPT）的提出

**混合配电变压器（Hybrid Power Transformer, HPT）** 将线频变压器（LFT）与仅占总容量10–30%的电力电子变换器相结合，以最低成本实现快速、连续的电压调节：

```
传统配变：廉价、可靠，但调节慢（LTC步长 1.25%，动作 3–8 s）
全固态变压器（SST）：完全可控，但成本高（86 $/kVA）、效率低（~97%）
HPT（本研究）：效率≥96%，成本接近传统变压器（~31 $/kVA），调节速度<5 ms
```

### 1.3 本研究目标与技术指标

**硬件指标**（课题任务书）：

| 指标 | 要求 | 本模型 |
|------|------|--------|
| 总容量 | 400 kVA | 400 kVA |
| 电力电子容量 | ≥ 120 kVA | 120 kVA (30%) |
| 最高效率 | ≥ 96% | — |
| 电压调节范围 | ≥ ±20% | ±20% V_grid |
| 动态响应时间 | < 5 ms | < 5 ms |

**研究问题**：在上述硬件约束下，如何通过AI方法使HPT在多类故障下保持低电压穿越（LVRT）能力，同时提高故障检测速度和准确率？

## 2. 系统拓扑与理论基础

### 2.1 HPT主电路拓扑

本研究采用**两绕组主变压器 + 外接串并联变换器**方案：

```
  ┌──────────────────────────────────────────────────────────────┐
  │                   10 kV MV 配电网                            │
  └───────────────┬──────────────────────────────────────────────┘
                  │  İ₁ (线电流)
                  ▼
         ┌────────────────┐
         │   VSC_se × 3   │  ← 3个单相H桥，串联于一次侧
         │  (调节变换器)   │    每相注入 V̇_se，最大 ±1155 V
         └───────┬────────┘
                 │  V̇₁ - V̇_se
                 ▼
    ┌────────────────────────┐
    │  主变压器 (Δ-Yg)       │  10 kV / 400 V，400 kVA
    │  k = 25, X_T = 0.05 pu│  Δ接一次，Yg接二次
    └──────────┬─────────────┘
               │  V̇₂ (400 V 二次侧)
               ├──────────────────────► 负载
               │
               ▼
    ┌────────────────────────┐
    │   VSC_sh (能量提取)    │  3相桥，120 kVA，并联于二次侧
    │  维持 V_dc, 无功补偿   │  L_sh=3 mH, R_sh=0.05 Ω
    └──────────┬─────────────┘
               │
               ▼
    ┌────────────────────────┐
    │  DC 母线               │  V_dc = 800 V, C_dc = 2200 μF
    │  E = 704 J             │  VSC_se 与 VSC_sh 共用直流
    └────────────────────────┘
```

| 参数 | 符号 | 数值 |
|------|------|------|

| 一次侧线电压 | V₁_LL | 10 kV |
| 二次侧线电压 | V₂_LL | 400 V |

| 并联VSC容量 | S_sh | 120 kVA |
| 开关频率 | f_sw | 5 kHz |
| 采样频率 | f_s | 20 kHz |

### 2.2 磁路与绕组方程

对于Δ-Yg接线的主变压器（参考Lai et al. 2026, eq.1–5的三绕组推广），二次侧电压满足：

$$\frac{\dot{V}_{MVx}}{N_{MV}} + \frac{\dot{V}_{SCx}}{N_{SC}} = \frac{\dot{V}_{LVx}}{N_{LV}} \tag{2.1}$$

其中 $N_{MV}$、$N_{SC}$、$N_{LV}$ 分别为一次、串联、二次绕组匝数。对于本研究的两绕组外接H桥方案，等效形式为：

$$\dot{V}_1 = \dot{V}_{se} + k\dot{V}_{m1} + jX_T \dot{I}_1 \tag{2.2}$$

$$k\dot{I}_1 = \dot{I}_2 + \dot{I}_{sh} \tag{2.3}$$

式中 $\dot{V}_{se}$ 为串联H桥注入电压，$\dot{V}_{m1}$ 为主变一次绕组电压，$X_T$ 为漏抗，$\dot{I}_{sh}$ 为并联VSC注入电流。

**Δ-Y相位偏移**（关键修正，Lai 2026 eq.7）：

$$v_{LV,x,\text{ref}} = V_{LV} \sin\!\left(\theta + \frac{\pi}{6} + \frac{2p\pi}{3}\right), \quad p=0,-1,1 \tag{2.4}$$

Δ-Yg连接引入固定30°（π/6）相位差。串联VSC的SPWM参考角必须包含此偏移，否则注入相位错误，在不对称故障下产生附加误差。

### 2.3 功率流分析

忽略变换器损耗，DC侧功率平衡方程为（Liu et al. 2021, eq.25）：

$$p_{DC} = p_s - p_2 = p_{sh} + p_{se} \tag{2.5}$$

其中 $p_s$ 为从电网吸收的总功率，$p_2$ 为负荷功率，$p_{sh}$ 为VSC_sh功率，$p_{se}$ 为VSC_se功率。

$$p_{sh} = V_2 I_{sh} \cos(\theta_2 - \theta_{sh}) \tag{2.6}$$
$$p_{se} = V_{se} I_1 \cos(\theta_{se}) \tag{2.7}$$

DC母线电压动态方程（线性化，Liu 2021 eq.40）：

$$G_{uD}(s) = \frac{u_D(s)}{i_{Psd}(s)} = \frac{3\sqrt{2}\,U_{1N}}{C_D U_D s} \tag{2.8}$$

代入参数：$U_{1N}=400/\sqrt{3}$ V，$C_D=2200\,\mu\text{F}$，$U_D=800\,\text{V}$：

$$G_{uD}(s) = \frac{612.4}{1.76 \times 10^{-3}\,s} \tag{2.9}$$

### 2.4 dq同步旋转坐标系模型

令 $\theta = 2\pi f_1 t + \pi/6$ 为相位参考（含Δ-Y偏移），对(2.2)(2.3)式做Park变换：

$$\begin{cases}
V_{1d} = V_{se,d} + kV_{2d} \\
V_{1q} = V_{se,q} + kV_{2q} + X_T I_{1d} \\
kI_{1d} = I_{2d} + I_{sh,d} \\
kI_{1q} = I_{2q} + I_{sh,q}
\end{cases} \tag{2.10}$$

DC侧能量守恒：

$$V_{se,d} I_{1d} + V_2 (I_{2d} + I_{2q}) - V_{se,d} \frac{I_{2d}+I_{2q}}{k}(I_{sh,d}+I_{sh,q}) = 0 \tag{2.11}$$

由(2.10)可得V₂调节控制律（Shang 2024, eq.17）：

$$V_{se,d} = \frac{V_{1d}}{k} - V_{2d} + \left(k_{p1} + \frac{k_{i1}}{s}\right) \cdot \frac{V_{2,\text{rms,ref}}^2 - V_{2,\text{rms}}^2}{V_{1d}/k + V_{2d}} \tag{2.12}$$

### 2.5 LVRT判据

根据工程实际与中国标准（GB/T 36995参考），本研究制定四维LVRT通过准则：

| 判据 | 表达式 | 物理含义 |
|------|--------|---------|
| DC电压下限 | $V_{dc,\min} \geq 0.75\,\text{pu}$ | VSC控制权威性下限（600 V） |
| DC电压上限 | $V_{dc,\max} \leq 1.25\,\text{pu}$ | 电容过压保护（1000 V） |
| 输出电流限 | $I_{2,\max} \leq 3.0\,\text{pu}$ | 过流保护 |
| 电压恢复时间 | $t_{\text{recovery}} \leq 100\,\text{ms}$ | 供电恢复速度 |

## 4. 传统控制与检测方法

### 4.1 规则型FRT控制器

**原理**：基于实时测量V₂和V_dc，用固定阈值规则直接输出调制指数m：

```
if V₂_pu < 0.98：
    sag = 0.98 - V₂_pu
    m = clip(0.045 + 0.42 × sag, 0.02, 0.24)
else：
    m = 0.045（小量注入维持稳定）

if V_dc < 720 V：  m = min(m, 0.06)   # 保护DC欠压
if V_dc > 960 V：  m = min(m, 0.04)   # 保护DC过压
if I₂ > 2.0 pu：   m = min(m, 0.02)   # 限流保护
```

**优点**：无需训练数据，实现简单，计算量极小  
**缺点**：无法区分故障类型，参数固定不可调，对超阈值场景（sc_3ph）无能为力

**LVRT通过率（350场景）**：60.57%

---

### 4.2 dq双环PI控制（基准最优方法）

dq控制是本研究的**最强传统基准**，分内外两环：

#### 外环：DC母线电压控制

误差信号：
$$e_{vdc}(t) = \frac{V_{dc,\text{ref}} - |V_{dc}(t)|}{V_{dc,\text{ref}}} \tag{4.1}$$

PI积分器（修正后参数）：
$$i_{vdc}^{\text{int}} = \text{clip}\!\left(i_{vdc}^{\text{int}} + e_{vdc} \cdot \Delta t \cdot 350,\ {-0.35},\ {+0.35}\right) \tag{4.2}$$

调制指数计算：
$$m_{sh} = 0.68 + K_{p,vdc} \cdot e_{vdc} + K_{i,vdc} \cdot i_{vdc}^{\text{int}} \tag{4.3}$$

修正后参数：$K_{p,vdc}=0.30$，$K_{i,vdc}=16.5$（原 0.30, 2.17）。  
修正依据：Liu 2021 建议 $\omega_{PI}=K_i/K_p = 55\,\text{rad/s}$；原始设计仅3.14 rad/s，导致DC稳态误差约3%（776 V vs 800 V）。

#### 内环：电流控制（含dq解耦）

并联VSC在dq框架下的电流方程：

$$L_{sh}\frac{di_d}{dt} = u_d - R_{sh} i_d + \omega_0 L_{sh} i_q - e_d \tag{4.4}$$
$$L_{sh}\frac{di_q}{dt} = u_q - R_{sh} i_q - \omega_0 L_{sh} i_d - e_q \tag{4.5}$$

为消除d-q轴耦合项 $\pm\omega_0 L_{sh} i_{d,q}$，引入前馈解耦：

$$u_{d,\text{ref}} = \underbrace{K_p^{ish}(i_{d,\text{ref}}-i_d) + K_i^{ish}\int(i_{d,\text{ref}}-i_d)dt}_{\text{PI项}} - \underbrace{\omega_0 L_{sh} i_q}_{\text{解耦前馈}} \tag{4.6}$$

参数（5 kHz开关，500 Hz带宽目标）：

$$K_p^{ish} = L_{sh} \cdot 2\pi \times 500 = 9.42, \quad K_i^{ish} = R_{sh} \cdot 2\pi \times 500 = 157 \tag{4.7}$$

#### 陷波滤波器（文献推荐，待实施）

纯PI控制在不对称负荷下，$(p_f - p_2)$ 的交流分量进入 $i_{Psd,\text{ref}}$，导致电网电流THD达12–21%（Liu 2021）。推荐在DC误差路径上串联三个陷波滤波器：

$$G_{BEF,n}(s) = \frac{s^2 + \omega_n^2}{s^2 + (\omega_n/Q)\,s + \omega_n^2}, \quad \omega_n \in \{\omega_0, 2\omega_0, 3\omega_0\}, \quad Q=3 \tag{4.8}$$

**dq控制LVRT通过率（350场景）**：**64.00%**（所有控制方法中最高）

### 4.3 传统故障检测方法

#### 4.3.1 阈值-质心法（Rule-based）

基于V_dc、I₂均值的多阈值判断：

```python
if   Vdc_mean < 700 and dI_max > 0.5 pu:  class = sc_3ph
elif Vdc_mean < 720 and dVdc_rate > 50:    class = cap_fault
elif I2_asymm > 0.3 pu:                    class = sc_1ph
elif Ish_d_drop > 0.4 pu:                  class = igbt_oc_sh
else:                                       class = normal
```

**结果**：准确率 59.50%，宏观F1 36.34%（大量类混淆）

#### 4.3.2 极限学习机（ELM）

ELM是单隐层前馈网络，通过随机初始化输入权重 $\mathbf{W}$、偏置 $\mathbf{b}$，仅训练输出权重 $\boldsymbol{\beta}$：

$$\hat{\mathbf{Y}} = \mathbf{H}\boldsymbol{\beta}, \quad \mathbf{H}_{ij} = g(\mathbf{W}_j \cdot \mathbf{x}_i + b_j) \tag{4.9}$$

$$\boldsymbol{\beta} = \mathbf{H}^\dagger \mathbf{Y} = (\mathbf{H}^T\mathbf{H})^{-1}\mathbf{H}^T \mathbf{Y} \tag{4.10}$$

输入：对100样本窗口（5 ms）提取9个统计特征 × 9通道 = 81维  
**结果**：准确率 90.67%，宏观F1 88.71%

#### 4.3.3 SVM-RBF

支持向量机使用径向基核函数：

$$K(\mathbf{x}_i, \mathbf{x}_j) = \exp\!\left(-\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2\right) \tag{4.11}$$

多分类采用one-vs-rest策略，共7个二分类SVM。  
**结果**：准确率 91.09%，宏观F1 89.53%

#### 4.3.4 随机森林（RF）

集成 $T=500$ 棵决策树，每棵树在 $\sqrt{d}$ 个随机特征子集上生长：

$$\hat{y} = \text{majority\_vote}\bigg\{h_t(\mathbf{x})\bigg\}_{t=1}^{T} \tag{4.12}$$

输入特征：对9通道信号计算9类统计量（均值、标准差、RMS、峰峰值、趋势、平均绝对差分等）= **81维**  
**结果**：准确率 **97.71%**，宏观F1 **97.34%**（传统方法最强）

**RF成功的原因**：
1. 正常类样本占43%，RF的自助采样天然对多数类高效
2. 81维统计/FFT特征对稳态窗口已高度判别化
3. 决策树集成对类不均衡具有鲁棒性

## 5. AI故障检测方法：MSFFN

### 5.1 特征工程：14通道输入

**核心洞见（来自文献综述）**：

| 旧方案 (9通道) | 新方案 (14通道) | 新增通道的物理意义 |
|--------------|---------------|-----------------|
| V_dc, dc_err_proxy, Iq2_kA | 保留 | — |
| I1_a/b/c | 保留 | — |
| I2_a/b/c | 保留 | — |
| — | **Ise_d, Ise_q** | 串联VSC dq电流：igbt_oc_se时 $I_{se}≈0$，是最直接的诊断信号（Lai 2026） |
| — | **V2_a, V2_b, V2_c** | 二次侧相电压：区分对称（sc_3ph, V₂→0全相）vs 不对称（sc_1ph, 单相跌落）（Liu 2021） |

对每个 `.mat` 文件的时序信号，以步长100（5 ms）提取滑动窗口：

### 5.2 MSFFN三分支架构

**Multi-Scale Feature Fusion Network (MSFFN)** 针对HPT故障诊断特点设计了三条并行特征提取分支：

```
输入 x ∈ ℝ^(B×100×14)
         │
    ┌────┴────┬──────────────┐
    ▼         ▼              ▼
┌────────┐ ┌────────┐ ┌────────────┐
│ 分支A  │ │ 分支B  │ │  分支C     │
│ 统计量  │ │  FFT   │ │  TCN时序   │
│ MLP    │ │  MLP   │ │  因果卷积  │
└───┬────┘ └───┬────┘ └─────┬──────┘
    │(128维)   │(128维)     │(128维)
    └──────────┴─────────────┘
                 │
          ┌──────▼───────┐
          │  门控注意力  │  权重w=(w_A, w_B, w_C)
          │  Softmax(3)  │  按样本动态分配
          └──────┬───────┘
                 │  fused = w_A·a + w_B·b + w_C·c  ∈ ℝ^(B×128)
                 ▼
          ┌──────────────┐
          │  分类头      │
          │ Linear(128→64→7)
          └──────────────┘
                 │
          输出 logits ∈ ℝ^(B×7)
```

#### 分支A：统计量 MLP（81→256→128 或 126→256→128）

对窗口 $\mathbf{x} \in \mathbb{R}^{100 \times C}$ 沿时间维计算9类统计量：

$$\phi_A(\mathbf{x}) = \big[\bar{x},\ \sigma_x,\ x_{\text{RMS}},\ x_{\min},\ x_{\max},\ \Delta x_{\text{pp}},\ x_{T}-x_0,\ \overline{|\Delta x|},\ \max|\Delta x|\big] \in \mathbb{R}^{9C} \tag{5.2}$$

其中 $C=14$ 通道，输出126维（原9通道时81维）。

$$a = \text{MLP}_A(\phi_A(\mathbf{x})) \in \mathbb{R}^{128} \tag{5.3}$$

**作用**：捕获稳态幅值特征，对sc_3ph的深度对称电压跌落（统计均值下降明显）最有效。

#### 分支B：FFT 频谱 MLP（364→256→128）

取前26个FFT幅度系数（对应200–5200 Hz频带）：

$$\phi_B(\mathbf{x}) = \big|\text{FFT}(\mathbf{x})\big|_{1:26} \in \mathbb{R}^{26 \times C} \rightarrow \mathbb{R}^{26C} \tag{5.4}$$

$$b = \text{MLP}_B(\phi_B(\mathbf{x})) \in \mathbb{R}^{128} \tag{5.5}$$

**作用**：捕获谐波特征。cap_fault因电容退化产生DC纹波频率特征；sc_1ph产生2次谐波不对称成分。

#### 分支C：因果时序卷积网络（TCN）

三层扩张因果卷积，有效感受野覆盖100个时间步：

```python
LightTCN：
  Conv1d(14→32, k=1) + BN + GELU + ResBlock(dilation=1)
  Conv1d(32→64, k=1) + BN + GELU + ResBlock(dilation=2)
  Conv1d(64→128,k=1) + BN + GELU + ResBlock(dilation=4)
  AdaptiveAvgPool1d(1) → Linear(128→128)
```

因果卷积（无未来数据泄露）：

$$\text{CausalConv}(x, k, d) = \text{Conv1d}(x; \text{padding}=(k-1)d)[\ldots, :-(k-1)d] \tag{5.6}$$

**作用**：捕获故障发生时的暂态时序特征。IGBT开路时 $I_{se}$ 在毫秒内从额定值跌至零，产生尖锐边沿；cascade故障呈现多峰时序。

#### 门控注意力融合

$$\mathbf{w} = \text{Softmax}\big(\text{MLP}_{\text{gate}}([a;b;c])\big) \in \mathbb{R}^{3} \tag{5.7}$$

$$\mathbf{f} = w_A \cdot a + w_B \cdot b + w_C \cdot c \in \mathbb{R}^{128} \tag{5.8}$$

门控网络根据每个样本的特征动态分配三个分支的权重，使模型**按故障类型自适应选择最优特征**。

### 5.3 训练策略

**损失函数**：Focal Loss（应对类别不均衡）

$$\mathcal{L}_\text{focal} = -\sum_i \alpha_{y_i}(1-p_{y_i})^\gamma \log p_{y_i} \tag{5.9}$$

其中 $\alpha_c \propto 1/\sqrt{n_c}$（少数类权重放大），$\gamma=1.5$（聚焦因子）。

**类别平衡采样**：使用 `WeightedRandomSampler`，每个样本的采样权重 $w_i = 1/n_{y_i}$，确保每个mini-batch中各类样本均匀分布。

**数据增强**（仅训练集）：

$$\mathbf{x}' = (\mathbf{x} + \epsilon) \cdot s,\quad \epsilon \sim \mathcal{N}(0, 0.02^2),\quad s \sim \mathcal{U}(0.90, 1.10) \tag{5.10}$$

附加随机时间偏移 $\pm 2$ 步（±0.1 ms），模拟采样时刻抖动。

**优化配置**：

| 超参数 | 值 |
|--------|-----|
| 优化器 | Adam（lr=1e-3, weight_decay=1e-5） |
| 学习率调度 | CosineAnnealingLR（T_max=epoch数, η_min=1e-5） |
| 批量大小 | 256 |
| 早停 | patience=8（验证集宏观F1） |
| 最大轮数 | 50 |

**训练历史**（实际在第6轮早停）：

| Epoch | Loss | Val Acc | Val Macro F1 |
|-------|------|---------|--------------|
| 1 | 18.17 | 99.82% | 99.16% |
| 3 | 3.30 | 99.83% | 99.25% ← **最优** |
| 6 | 1.78 | 99.82% | 99.24% |
| 11 | 1.55 | 99.83% | 99.19% |
| → 早停 | — | — | 保存epoch 3 |

极快收敛原因：14通道特征（尤其Ise_dq）信息量充分，网络无需多轮迭代即可学习到判别规律。

## 6. AI控制方法：FAHC / PPO / DNN

### 6.1 故障感知分层控制器（FAHC）

#### 设计思路

FAHC的核心洞见来自能量守恒分析：

$$\Delta E = \frac{1}{2}C_{dc}(V_{dc,\text{nom}}^2 - V_{dc,\text{ref,new}}^2) \tag{6.1}$$

当故障导致V_dc下跌时，若提前将参考值从800 V降至720 V，可节省能量：

$$\Delta E(800 \to 720\,\text{V}) = \frac{1}{2} \times 2200\,\mu\text{F} \times (800^2 - 720^2) = 134\,\text{J} \tag{6.2}$$

这134 J足以将 $V_{dc,\min}$ 提升约：

$$\Delta V_{dc} \approx \frac{\Delta E}{C_{dc} \cdot V_{dc,\text{nom}}} = \frac{134}{2200 \times 10^{-6} \times 800} \approx 76\,\text{V} \approx 0.095\,\text{pu} \tag{6.3}$$

对于边界失败场景（$V_{dc,\min} \in [0.65, 0.75]$ pu），0.095 pu的提升可使其越过LVRT阈值0.75 pu。

#### 四级策略表

| 策略 | 适用故障 | V_dc,ref | V₂_ref | I_lim | 节能 ΔE |
|------|---------|---------|-------|-------|---------|
| S0 | normal, igbt_oc_sh, igbt_oc_se | 800 V | 400 V | 3.0 pu | 0 J |
| S1 | cap_fault | 760 V | 400 V | 2.8 pu | 68 J |
| S2 | sc_1ph | 740 V | 380 V | 2.8 pu | 101 J |
| S3 | sc_3ph, cascade | 720 V | 360 V | 2.5 pu | 134 J |

#### 流程图

```
                    ┌─────────────────┐
  V2_abc ──────────►│  MSFFN v2       │ 5ms实时推理
  I2_abc           │  (14通道窗口)    │
  V_dc             │  99.86%准确率    │
  I1_abc           └────────┬────────┘
  Ise_dq                    │ 预测类别 ĉ + 置信度 p̂
                             │
                    ┌────────▼────────┐
                    │ 置信度门控       │
                    │ if p̂ < τ=0.80  │──────► 保持S0（默认安全）
                    └────────┬────────┘
                             │ p̂ ≥ τ
                    ┌────────▼────────┐
                    │ 策略映射        │
                    │ ĉ→策略 (S0~S3) │
                    └────────┬────────┘
                             │ 策略ID
                    ┌────────▼────────┐
                    │ 执行策略        │
                    │ 更新V_dc,ref    │
                    │ 更新V₂_ref      │
                    │ 更新I_limit     │
                    └─────────────────┘
```

#### ET-PIRC启发的动态升级（新增）

受Lai et al. 2026的事件触发PI-重复控制器（ET-PIRC）启发，引入动态策略升级机制（类比ET-PIRC的 $K_{ET}$ 动态调整）：

$$K_{ET}(t) = \frac{B}{1 + \|e_d(t)\|}, \quad B=0.5 \tag{6.4}$$

在FAHC中，等效地监测DC误差率和V₂误差率：

$$e_{vdc}(t) = \frac{V_{dc,\text{ref}} - V_{dc}(t)}{V_{dc,\text{ref}}}, \quad e_{v2}(t) = \frac{V_{2,\text{ref}} - V_{2,\text{rms}}(t)}{V_{2,\text{ref}}} \tag{6.5}$$

触发条件（类比ET-PIRC eq.28）：

$$|e_{vdc}| > A \cdot e_{\text{steady,vdc}} \quad \text{OR} \quad |e_{v2}| > A \cdot e_{\text{steady,v2}} \tag{6.6}$$

其中 $A=3.0$，$e_{\text{steady,vdc}}=0.03$，$e_{\text{steady,v2}}=0.02$。触发后策略等级临时上调 $+1$ 级（最多到S3），在2个基波周期（40 ms）内无重触发则回退。

### 6.2 PPO强化学习控制器

#### 状态与动作空间

状态观测 $\mathbf{s} \in \mathbb{R}^8$（场景级特征）：

$$\mathbf{s} = \left[\frac{sc\_id}{6},\ \frac{P_{\text{load}}}{400\,\text{kVA}},\ \frac{Q_{\text{load}}}{250\,\text{kVAR}},\ \frac{t_{\text{fault}}}{0.05},\ \frac{v_{\text{variant}}}{6},\ f_{\text{mag}},\ R_f,\ R_g \right] \tag{6.7}$$

动作 $\mathbf{a} \in \mathbb{R}^3$（归一化到 $[-1,+1]$）：
- $a_0$：DC母线参考偏置（映射至 $[-80, +40]$ V）
- $a_1$：V₂参考偏置（映射至 $[-40, +20]$ V）
- $a_2$：限流偏置（映射至 $[-0.5, +0.5]$ pu）

#### 奖励函数

$$r = \underbrace{4.0 \cdot \mathbb{1}[\text{LVRT pass}]}_{\text{通过奖励}} + \underbrace{2.0 \cdot \frac{V_{2,\min}}{0.90} + 2.0 \cdot \frac{V_{dc,\min}}{0.75}}_{\text{物理连续奖励}} - \underbrace{10.0 \max(0,\, 0.75-V_{dc,\min})}_{\text{欠压惩罚}} - \cdots \tag{6.8}$$

以物理量为中心的稠密奖励，使PPO在失败场景中也能获得学习信号（哪个物理量更接近阈值）。

#### 网络结构（Actor-Critic）

```
输入 s (8维)
  ↓
Linear(8→128) + Tanh
Linear(128→128) + Tanh
  ├── mu头: Linear(128→3) + Tanh   → 动作均值
  ├── log_std: 可学习参数 (3,)      → 动作方差
  └── value头: Linear(128→1)        → 状态价值
```

**PPO LVRT通过率（350场景）**：59.43%（低于规则FRT，原因：场景观测为场景级别，缺乏实时信号，且Simulink回调慢导致探索不足）

### 6.3 DNN仿制控制器（历史方法）

**注意**：此方法在旧拓扑上训练，在修正后的HPT v2拓扑上无效（通过率约0.3%），已在正式对比中排除。

基本思路：DNN学习专家控制器（dq双环）的输入输出映射：

$$[\hat{V}_{se,d},\, \hat{V}_{se,q},\, \hat{I}_{sh,d}] = f_\theta\!\left([V_1,V_2,V_{dc},P_1,Q_1,P_2,\text{mode}]\right) \tag{6.9}$$

结构：7→256→256→128→3，MSE损失，在5000个稳态快照上训练，MAE=0.0028 pu。

### 6.4 参考条件网络（RCN）

RCN是FAHC的连续版本，直接输出参考量的连续偏置：

$$[\Delta V_{dc,\text{ref}},\, \Delta V_{2,\text{ref}},\, \Delta I_{\text{lim}}] = \text{RCN}_\theta(\mathbf{s}) \tag{6.10}$$

结构：Linear(8→256)+LN+GELU → Linear(256→256)+LN+GELU → Linear(256→64)+GELU → Linear(64→3)+Tanh

**两阶段训练**：
1. 离线阶段：用物理估算的最优参考（能量守恒）为目标，无需新仿真
2. 在线阶段（可选）：用Simulink网格搜索的真实最优参考重新训练

### 7.3 失败分析：硬件能量瓶颈

sc_3ph、sc_1ph、cap_fault三类故障的低通过率根本原因是**硬件储能不足**：

$$E_{\text{stored}} = 704\,\text{J}, \quad E_{\text{required}} \approx 2000\text{–}5000\,\text{J（深度三相短路）}$$

三相短路时 $I_{2,\max}=3.44\,\text{pu} > 3.0\,\text{pu}$ 限制，V₂跌至0.254 pu，任何软件控制均无法克服这一物理约束。

参考Zheng et al. 2022（SST/HST能量存储对比），将DC储能从704 J升至 ≥2000 J（需 $C_{dc} \approx 6250\,\mu\text{F}$ 或增加电池储能）是使三相故障通过率超过50%的**唯一可行路径**。
