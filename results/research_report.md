## 1. 项目背景

### 1.1 分布式能源接入带来的问题

随着光伏、风电等分布式能源大规模并网，配电网面临三类核心问题 \[1,3,4,6,8\]：

| 问题 | 描述 | 危害 |
|------|------|------|
| **电压越限** | PV注入功率导致馈线末端电压超出±10%范围 \[3,8\] | 频繁跳闸、设备损坏 |
| **电压波动** | 光照/负荷瞬变引起V₂在百毫秒内大幅摆动 \[4\] | 敏感负荷故障（CT/手术设备THD<6%）\[2\] |
| **故障穿越失败** | IGBT开路/短路/电容退化导致变换器失去控制能力 \[1,9\] | 停电、连锁反应 |

传统配电变压器依赖有载调压开关（LTC/OLTC）调节电压，动作时间数秒至分钟 \[6\]，无法满足<5 ms的快速响应要求。Lai等 \[2\] 特别指出，医疗CT扫描仪的电压畸变容限仅THD 3%–8%，外科手术设备仅3%–6%，即使短暂的电压扰动也可能造成数十万元的生产损失。

### 1.2 混合配电变压器（HPT）的提出

**混合配电变压器（Hybrid Power Transformer, HPT）** 将线频变压器（LFT）与仅占总容量10–30%的电力电子变换器相结合，以最低成本实现快速、连续的电压调节 \[1,3,4,6,8,9\]：

```
传统配变：廉价、可靠，但调节慢（LTC步长 1.25%，动作 3–8 s）[6]
全固态变压器（SST）：完全可控，但成本高（86 $/kVA）、效率低（~97%）[6]
HPT（本研究）：效率≥96%，成本接近传统变压器（~31 $/kVA），调节速度<5 ms [6]
```

Zheng等 \[6\] 对SST、HPT与传统LFT进行了首次系统性技术经济比较，证明HPT以约36%的SST成本实现了相当的电压调节能力，在IEEE 34节点系统中可使低压侧PV承载能力提升81.82%，年运营成本降低5.16%。

### 1.3 本研究目标与技术指标

**硬件指标**（课题任务书）：

| 指标 | 要求 | 本模型 |
|------|------|--------|
| 总容量 | 400 kVA | 400 kVA |
| 电力电子容量 | ≥ 120 kVA | 120 kVA (30%) |
| 最高效率 | ≥ 96% | — |
| 电压调节范围 | ≥ ±20% | ±20% V_grid \[3,8\] |
| 动态响应时间 | < 5 ms | < 5 ms |

**研究问题**：在上述硬件约束下，如何通过AI方法使HPT在多类故障下保持低电压穿越（LVRT）能力，同时提高故障检测速度和准确率？

## 2. 系统拓扑与理论基础

### 2.1 HPT主电路拓扑

本研究采用**两绕组主变压器 + 外接串并联变换器**方案，与Shang等 \[3\]、唐爱红等 \[8\] 及宋幸 \[9\] 研究的HPT拓扑完全一致：

```
  ┌──────────────────────────────────────────────────────────────┐
  │                   10 kV MV 配电网                            │
  └───────────────┬──────────────────────────────────────────────┘
                  │  İ₁ (线电流)
                  ▼
         ┌────────────────┐
         │   VSC_se × 3   │  ← 3个单相H桥，串联于一次侧 [3,8,9]
         │  (调节变换器)   │    每相注入 V̇_se，最大 ±1155 V
         └───────┬────────┘
                 │  V̇₁ - V̇_se
                 ▼
    ┌────────────────────────┐
    │  主变压器 (Δ-Yg)       │  10 kV / 400 V，400 kVA
    │  k = 25, X_T = 0.05 pu│  Δ接一次，Yg接二次 [1,2]
    └──────────┬─────────────┘
               │  V̇₂ (400 V 二次侧)
               ├──────────────────────► 负载
               │
               ▼
    ┌────────────────────────┐
    │   VSC_sh (能量提取)    │  3相桥，120 kVA，并联于二次侧 [1,3]
    │  维持 V_dc, 无功补偿   │  L_sh=3 mH, R_sh=0.05 Ω
    └──────────┬─────────────┘
               │
               ▼
    ┌────────────────────────┐
    │  DC 母线               │  V_dc = 800 V, C_dc = 2200 μF
    │  E = 704 J             │  VSC_se 与 VSC_sh 共用直流 [1,6]
    └────────────────────────┘
```

> **拓扑对比**：文献中另有两种常见结构。Lai等 \[2\] 及Liu等 \[1,5\] 使用**三绕组集成变压器**（Dyyn11接线，主变具有串联绕组），与外接H桥方案功能等效但无需额外耦合变压器。Zheng等 \[6\] 和Zhang等 \[4\] 使用**五绕组结构**（主变三绕组 + 隔离变压器两绕组），控制自由度更高但制造复杂。本研究选用两绕组外接方案，与 \[3,8,9\] 一致，具有维护便利性优势。

### 2.2 磁路与绕组方程

对于Δ-Yg接线，三绕组推广形式下二次侧电压满足（Lai et al. \[2\], eq.1–5）：

$$\frac{\dot{V}_{MVx}}{N_{MV}} + \frac{\dot{V}_{SCx}}{N_{SC}} = \frac{\dot{V}_{LVx}}{N_{LV}} \tag{2.1}$$

其中 $N_{MV}$、$N_{SC}$、$N_{LV}$ 分别为一次、串联、二次绕组匝数。对于本研究的两绕组外接H桥方案，等效形式为（Shang et al. \[3\], eq.1）：

$$\dot{V}_1 = \dot{V}_{se} + k\dot{V}_{m1} + jX_T \dot{I}_1 \tag{2.2}$$

$$k\dot{I}_1 = \dot{I}_2 + \dot{I}_{sh} \tag{2.3}$$

式中 $\dot{V}_{se}$ 为串联H桥注入电压，$\dot{V}_{m1}$ 为主变一次绕组电压，$X_T$ 为漏抗，$\dot{I}_{sh}$ 为并联VSC注入电流。

**Δ-Y相位偏移**（关键修正，Lai 2026 \[2\] eq.7）：

$$v_{LV,x,\text{ref}} = V_{LV} \sin\!\left(\theta + \frac{\pi}{6} + \frac{2p\pi}{3}\right), \quad p=0,-1,1 \tag{2.4}$$

Δ-Yg连接引入固定30°（π/6）相位差 \[2\]。串联VSC的SPWM参考角必须包含此偏移，否则注入相位错误，在不对称故障（sc_1ph、cascade）下产生附加误差。本研究已将此修正纳入仿真模型（D1修正）。

### 2.3 功率流分析

忽略变换器损耗，DC侧功率平衡方程为（Liu et al. \[1\], eq.25）：

$$p_{DC} = p_s - p_2 = p_{sh} + p_{se} \tag{2.5}$$

其中 $p_s$ 为从电网吸收的总功率，$p_2$ 为负荷功率，$p_{sh}$ 为VSC_sh功率，$p_{se}$ 为VSC_se功率 \[1,3\]：

$$p_{sh} = V_2 I_{sh} \cos(\theta_2 - \theta_{sh}) \tag{2.6}$$
$$p_{se} = V_{se} I_1 \cos(\theta_{se}) \tag{2.7}$$

DC母线电压动态方程（线性化，Liu et al. \[1\] eq.40）：

$$G_{uD}(s) = \frac{u_D(s)}{i_{Psd}(s)} = \frac{3\sqrt{2}\,U_{1N}}{C_D U_D s} \tag{2.8}$$

代入参数：$U_{1N}=400/\sqrt{3}$ V，$C_D=2200\,\mu\text{F}$，$U_D=800\,\text{V}$：

$$G_{uD}(s) = \frac{612.4}{1.76 \times 10^{-3}\,s} \tag{2.9}$$

唐爱红等 \[8\] 进一步在稳态潮流计算框架下建立了HPT的等效注入功率模型，通过功率注入法将HPT电压调节模式和潮流调控模式分别建模，在IEEE 39和IEEE 118节点系统验证了潮流计算精度误差小于0.1%。

### 2.4 dq同步旋转坐标系模型

令 $\theta = 2\pi f_1 t + \pi/6$ 为相位参考（含Δ-Y偏移 \[2\]），对(2.2)(2.3)式做Park变换（Shang 2024 \[3\], eq.13）：

$$\begin{cases}
V_{1d} = V_{se,d} + kV_{2d} \\
V_{1q} = V_{se,q} + kV_{2q} + X_T I_{1d} \\
kI_{1d} = I_{2d} + I_{sh,d} \\
kI_{1q} = I_{2q} + I_{sh,q}
\end{cases} \tag{2.10}$$

DC侧能量守恒 \[1,3\]：

$$V_{se,d} I_{1d} + V_2 (I_{2d} + I_{2q}) - V_{se,d} \frac{I_{2d}+I_{2q}}{k}(I_{sh,d}+I_{sh,q}) = 0 \tag{2.11}$$

由(2.10)可得V₂调节控制律（Shang 2024 \[3\], eq.17）：

$$V_{se,d} = \frac{V_{1d}}{k} - V_{2d} + \left(k_{p1} + \frac{k_{i1}}{s}\right) \cdot \frac{V_{2,\text{rms,ref}}^2 - V_{2,\text{rms}}^2}{V_{1d}/k + V_{2d}} \tag{2.12}$$

Shang等 \[3\] 通过PSCAD仿真验证，该控制律使HPT在光照从1000 W/m²骤变时，二次侧电压波动时间压缩至0.1 s内，比无HPT控制响应速度快约6%。

### 2.5 LVRT判据

根据工程实际与中国标准（GB/T 36995参考），结合 \[1\] 中对DC母线控制权威性的分析，本研究制定四维LVRT通过准则：

| 判据 | 表达式 | 物理含义 | 来源 |
|------|--------|---------|------|
| DC电压下限 | $V_{dc,\min} \geq 0.75\,\text{pu}$ | VSC控制权威性下限（600 V）\[1\] | \[1\] |
| DC电压上限 | $V_{dc,\max} \leq 1.25\,\text{pu}$ | 电容过压保护（1000 V） | — |
| 输出电流限 | $I_{2,\max} \leq 3.0\,\text{pu}$ | 过流保护 \[10,11\] | — |
| 电压恢复时间 | $t_{\text{recovery}} \leq 100\,\text{ms}$ | 供电恢复速度（ET-PIRC实现20 ms内 \[2\]） | \[2\] |

Liu等 \[1\] 明确指出：DC母线电压远低于额定值时，变换器将失去控制能力，HPT整体停止运行，因此0.75 pu是实际可操作的最低阈值。Lai等 \[2\] 实验验证ET-PIRC可在1个基波周期（20 ms）内完成电压恢复，远优于本研究设定的100 ms宽松标准，为未来改进预留空间。

### 3.2 七类故障场景

故障场景的设计参考了 \[1,3,8,9\] 中对HPT常见故障模式的分析，以及 \[10,11\] 对电力电子变换器故障穿越机制的讨论：

```
故障类型分类（sc_id）：
                     ┌─ 正常运行 (0: normal)
                     │
  内部器件故障 ─────┼─ IGBT开路（并联VSC侧）(1: igbt_oc_sh)  ← 见[1,4,9]
  [1,4,9]           └─ IGBT开路（串联VSC侧）(2: igbt_oc_se)  ← 见[2,9]
                     
  DC储能故障 ────────── DC电容退化（容值降至50%）(3: cap_fault)  ← 见[1,5,6]

                     ┌─ 单相接地短路 (4: sc_1ph)              ← 见[2,3,10]
  外部电网故障 ─────┼─ 三相短路 (5: sc_3ph)                   ← 见[2,6,10,11]
  [2,3,10,11]       └─ 连锁故障（先单相后三相）(6: cascade)   ← 见[9,10]
```

**各故障类别的文献背景**：

- **igbt_oc_sh / igbt_oc_se**：Zhang等 \[4\] 和宋幸 \[9\] 指出，IGBT开路是HDT内部最常见故障模式，发生后应立即切除故障相并以降额模式运行。Lai等 \[2\] 通过三绕组绕组磁路方程（eq.3–5）分析了串联变换器IGBT开路时磁通分配的变化。

- **cap_fault**：Liu等 \[1,5\] 详细分析了DC母线电容退化对HPT运行稳定性的影响。 \[5\] 的软启动分析中指出，预充电阶段电容异常时需要额外保护策略。

- **sc_1ph / sc_3ph**：Shang等 \[3\] 在PSCAD仿真中模拟了三相短路工况下HPT电压调节响应；Lai等 \[2\] 用实验验证ET-PIRC在三相83%电压骤降时维持LV侧电压稳定（THD仅1.75%）。贾科等 \[10,11\] 针对柔直系统和构网型变流器的类似短路故障，提出了电流协同优化和虚拟阻感比自适应方法，为本研究限流策略提供了参考。

- **cascade**：宋幸 \[9\] 研究了HPT多模式切换时的连锁故障风险，贾科等 \[10\] 讨论了柔直受端换流站连锁故障的处理机制。

**场景生成规则**：
- 固定场景表：350个（7类 × 50次，种子=20260525），保证所有方法在完全相同的350个测试用例上比较
- 负荷范围：P_load ∈ [0.5, 1.0] S_rated，Q_load ∈ [0, 0.4] S_rated（参照 \[3,8\] 中仿真负荷设置）
- 故障参数：t_fault ∈ [0.3, 1.7] s，R_f ∈ [0.005, 0.1] Ω
- 训练数据集：840个场景（5种控制模式 × 168个场景/模式）

## 4. 传统控制与检测方法

### 4.1 规则型FRT控制器

**原理**：基于实时测量V₂和V_dc，用固定阈值规则直接输出调制指数m，属于"无感知"的保守策略：

```
if V₂_pu < 0.98：
    sag = 0.98 - V₂_pu
    m = clip(0.045 + 0.42 × sag, 0.02, 0.24)
else：
    m = 0.045（小量注入维持稳定）

if V_dc < 720 V：  m = min(m, 0.06)   # 保护DC欠压
if V_dc > 960 V：  m = min(m, 0.04)   # 保护DC过压
if I₂ > 2.0 pu：   m = min(m, 0.02)   # 限流保护 [10,11]
```

**优点**：无需训练数据，实现简单，计算量极小  
**缺点**：无法区分故障类型（与 \[2,9\] 对比明显），参数固定不可调，对超阈值场景（sc_3ph）无能为力

**LVRT通过率（350场景）**：60.57%

### 4.2 dq双环PI控制（基准最优方法）

dq控制是本研究的**最强传统基准**，在 \[1,3,8\] 中均有详细建模，分内外两环：

#### 外环：DC母线电压控制

误差信号：
$$e_{vdc}(t) = \frac{V_{dc,\text{ref}} - |V_{dc}(t)|}{V_{dc,\text{ref}}} \tag{4.1}$$

调制指数计算（PI外环）：
$$m_{sh} = 0.68 + K_{p,vdc} \cdot e_{vdc} + K_{i,vdc} \cdot \int e_{vdc}\,dt \tag{4.2}$$

**修正后参数**：$K_{p,vdc}=0.30$，$K_{i,vdc}=16.5$，$\omega_{PI}=K_i/K_p=55$ rad/s。  
修正依据：Liu等 \[1\] Table II 建议 $\omega_{PI}=55$ rad/s（PI+陷波滤波器方案），纯PI推荐400 rad/s；原始设计仅3.14 rad/s，导致DC稳态误差约3%（776 V vs 800 V参考值）。

#### 内环：电流控制（含dq解耦）

并联VSC在dq框架下的电流方程 \[1,3\]：

$$L_{sh}\frac{di_d}{dt} = u_d - R_{sh} i_d + \omega_0 L_{sh} i_q - e_d \tag{4.3}$$
$$L_{sh}\frac{di_q}{dt} = u_q - R_{sh} i_q - \omega_0 L_{sh} i_d - e_q \tag{4.4}$$

为消除d-q轴耦合项 $\pm\omega_0 L_{sh} i_{d,q}$，引入前馈解耦（参照 \[1\] 设计方法）：

$$u_{d,\text{ref}} = \underbrace{K_p^{ish}(i_{d,\text{ref}}-i_d) + K_i^{ish}\int(i_{d,\text{ref}}-i_d)dt}_{\text{PI项}} - \underbrace{\omega_0 L_{sh} i_q}_{\text{解耦前馈}} \tag{4.5}$$

参数（5 kHz开关，500 Hz带宽目标，参照 \[1\] 设计准则）：

$$K_p^{ish} = L_{sh} \cdot 2\pi \times 500 = 9.42, \quad K_i^{ish} = R_{sh} \cdot 2\pi \times 500 = 157 \tag{4.6}$$

#### 陷波滤波器（依据 \[1\] 推荐，待实施）

Liu等 \[1\] 通过理论推导和实验验证指出：纯PI控制在不对称负荷下，$(p_f - p_2)$ 的交流分量进入 $i_{Psd,\text{ref}}$，导致电网电流THD高达12–21%（实验测量值）。推荐在DC误差路径上串联三个陷波滤波器（\[1\] eq.48–53）：

$$G_{BEF,n}(s) = \frac{s^2 + \omega_n^2}{s^2 + (\omega_n/Q)\,s + \omega_n^2}, \quad \omega_n \in \{\omega_0, 2\omega_0, 3\omega_0\}, \quad Q=3 \tag{4.7}$$

添加陷波滤波器后，Liu等 \[1\] 实验中THD从21%降至2%以下，DC超调电压从40 V降至20 V。本研究已在parameters.m中记录该设计参数，待后续Simulink实施。

**dq控制LVRT通过率（350场景）**：**64.00%**（所有控制方法中最高）

### 4.3 传统故障检测方法

**说明**：传统故障检测方法的输入与MSFFN相同（9通道或14通道信号窗口，5 ms），以保证比较公平性。

#### 4.3.1 阈值-质心法（Rule-based）

基于V_dc、I₂均值的多阈值判断，参考 \[9\] 中对HPT故障模式的经验描述：

```python
if   Vdc_mean < 700 and dI_max > 0.5 pu:  class = sc_3ph
elif Vdc_mean < 720 and dVdc_rate > 50:    class = cap_fault  # [1]: 电容退化导致DC振荡
elif I2_asymm > 0.3 pu:                    class = sc_1ph     # [3]: 不对称电流特征
elif Ish_d_drop > 0.4 pu:                  class = igbt_oc_sh # [1,4]: 并联VSC电流跌落
else:                                       class = normal
```

**结果**：准确率 59.50%，宏观F1 36.34%（大量类混淆，尤其cascade与igbt_oc_se难以区分）

#### 4.3.2 极限学习机（ELM）\[Huang et al., 2006\]

ELM通过随机初始化输入权重 $\mathbf{W}$、偏置 $\mathbf{b}$，仅训练输出权重 $\boldsymbol{\beta}$：

$$\hat{\mathbf{Y}} = \mathbf{H}\boldsymbol{\beta}, \quad \mathbf{H}_{ij} = g(\mathbf{W}_j \cdot \mathbf{x}_i + b_j) \tag{4.8}$$

$$\boldsymbol{\beta} = \mathbf{H}^\dagger \mathbf{Y} = (\mathbf{H}^T\mathbf{H})^{-1}\mathbf{H}^T \mathbf{Y} \tag{4.9}$$

输入：对100样本窗口（5 ms）提取9类统计特征 × 9通道 = 81维  
**结果**：准确率 90.67%，宏观F1 88.71%

#### 4.3.3 SVM-RBF \[Cortes & Vapnik, 1995\]

支持向量机使用径向基核函数：

$$K(\mathbf{x}_i, \mathbf{x}_j) = \exp\!\left(-\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2\right) \tag{4.10}$$

多分类采用one-vs-rest策略，共7个二分类SVM。  
**结果**：准确率 91.09%，宏观F1 89.53%

#### 4.3.4 随机森林（RF）\[Breiman, 2001\]

集成 $T=500$ 棵决策树，每棵树在 $\sqrt{d}$ 个随机特征子集上生长：

$$\hat{y} = \text{majority\_vote}\bigg\{h_t(\mathbf{x})\bigg\}_{t=1}^{T} \tag{4.11}$$

输入特征：9通道信号计算9类统计量（均值、标准差、RMS、峰峰值、趋势、平均绝对差分等）= **81维**  
**结果**：准确率 **97.71%**，宏观F1 **97.34%**（传统方法最强）

**RF成功的原因分析**（参照 \[1,8\] 对HPT特征的物理解析）：
1. 正常类样本占训练集77.9%，RF的自助采样对多数类高效
2. 81维统计特征对稳态窗口（HPT的大多数时间）已高度判别化 \[8\]
3. 对于igbt_oc_sh，RF依赖I1和Ish的幅值统计量（参照 \[1,4\] 的电流分析）

### 5.1 特征工程：14通道输入

**核心洞见（来自文献综述 \[1,2\]）**：

| 旧方案 (9通道) | 新方案 (14通道) | 新增通道的物理意义 | 文献依据 |
|--------------|---------------|-----------------|---------|
| V_dc, dc_err_proxy, Iq2_kA | 保留 | DC母线状态与VSC_sh控制信号 | \[1,3\] |
| I1_a/b/c | 保留 | 一次侧三相电流 | \[1,3,8\] |
| I2_a/b/c | 保留 | 二次侧三相电流 | \[1,3\] |
| — | **Ise_d, Ise_q** | 串联VSC dq电流：igbt_oc_se时 $I_{se}\approx0$，是最直接的诊断信号 | \[2\]（Lai 2026描述了SC绕组电流对开路故障的灵敏性）|
| — | **V2_a, V2_b, V2_c** | 二次侧相电压：区分对称（sc_3ph）vs不对称（sc_1ph）故障，以及cap_fault的DC纹波叠加 | \[1,3\]（Liu 2021分析了不对称工况下V₂的谐波特性）|

对每个 `.mat` 文件的时序信号，以步长100（5 ms）提取滑动窗口（5 ms检测窗口设计依据 \[2\] 中<5 ms响应目标）：

$$\mathbf{x}^{(n)} \in \mathbb{R}^{100 \times 14}, \quad y^{(n)} \in \{0,1,2,3,4,5,6\} \tag{5.1}$$

**数据集规模**（840个 `.mat` 文件，覆盖 \[1,3,9\] 所述的多种HPT工作模式）：

| 划分 | 样本数 | 说明 |
|------|--------|------|
| 训练集 | 240,800 | 70% |
| 验证集 | 51,600 | 15% |
| 测试集 | 51,600 | 15% |
| **合计** | **344,000** | 14通道，100步长 |

### 5.2 MSFFN三分支架构

**Multi-Scale Feature Fusion Network (MSFFN)** 针对HPT故障诊断的多尺度特征特点设计三条并行分支，融合思路受Kamal等 \[7\] 多端口SST数据驱动控制方法的启发（数据足够时，神经网络可直接学习物理系统的非线性映射）：

```
输入 x ∈ ℝ^(B×100×14)
         │
    ┌────┴────┬──────────────┐
    ▼         ▼              ▼
┌────────┐ ┌────────┐ ┌────────────┐
│ 分支A  │ │ 分支B  │ │  分支C     │
│ 统计量  │ │  FFT   │ │  TCN时序   │
│ MLP    │ │  MLP   │ │  因果卷积  │
└───┬────┘ └───┬────┘ └─────┬──────┘
    │(128维)   │(128维)     │(128维)
    └──────────┴─────────────┘
                 │
          ┌──────▼───────┐
          │  门控注意力  │  权重w=(w_A, w_B, w_C)
          │  Softmax(3)  │  按样本动态分配
          └──────┬───────┘
                 │  fused ∈ ℝ^(B×128)
                 ▼
          ┌──────────────┐
          │  分类头      │
          │ Linear(128→64→7)
          └──────────────┘
```

#### 分支A：统计量 MLP（126→256→128）

对窗口 $\mathbf{x} \in \mathbb{R}^{100 \times 14}$ 计算9类统计量（与RF特征集对齐，参照 \[1,8\] 对HPT稳态特征的物理描述）：

$$\phi_A(\mathbf{x}) = \big[\bar{x},\ \sigma_x,\ x_{\text{RMS}},\ x_{\min},\ x_{\max},\ \Delta x_{\text{pp}},\ x_{T}-x_0,\ \overline{|\Delta x|},\ \max|\Delta x|\big] \in \mathbb{R}^{9 \times 14 = 126} \tag{5.2}$$

**作用**：捕获稳态幅值特征。对sc_3ph最有效——三相短路时V₂均值趋向0，RMS骤降（刻画了 \[3,8\] 描述的三相对称电压跌落特征）。

#### 分支B：FFT 频谱 MLP（364→256→128）

取前26个FFT幅度系数（对应200–5200 Hz频带）：

$$\phi_B(\mathbf{x}) = \big|\text{FFT}(\mathbf{x})\big|_{1:26} \in \mathbb{R}^{26 \times 14} \tag{5.3}$$

**作用**：捕获谐波特征。cap_fault因电容退化产生DC纹波频率成分（Liu等 \[1\] 指出DC振荡是cap_fault的主要表现）；sc_1ph产生2次谐波不对称成分（Shang等 \[3\] 分析了单相故障时V₂的不对称谐波）。

#### 分支C：因果时序卷积网络（TCN）

三层扩张因果卷积，有效感受野覆盖100个时间步，保证**因果性**（不使用未来数据，满足 \[2\] 的<5 ms在线检测要求）：

```python
LightTCN（三层，dilation=1/2/4）：
  Conv1d(14→32) + BN + GELU + ResBlock(dilation=1)
  Conv1d(32→64) + BN + GELU + ResBlock(dilation=2)
  Conv1d(64→128)+ BN + GELU + ResBlock(dilation=4)
  AdaptiveAvgPool1d(1) → Linear(128→128)
```

**作用**：捕获故障发生时的暂态时序特征。igbt_oc_se故障时 $I_{se}$ 在毫秒内从额定值跌至零，产生尖锐阶跃边沿（Lai等 \[2\] 中SC绕组电流的故障响应特性是设计此特征的直接依据）；cascade故障呈现先单相后三相的多峰时序（参照 \[10\] 中连锁故障的时序分析）。

#### 门控注意力融合

$$\mathbf{w} = \text{Softmax}\big(\text{MLP}_{\text{gate}}([a;b;c])\big) \in \mathbb{R}^{3} \tag{5.4}$$
$$\mathbf{f} = w_A \cdot a + w_B \cdot b + w_C \cdot c \in \mathbb{R}^{128} \tag{5.5}$$

门控网络根据每个样本动态分配三个分支的权重，使模型**按故障类型自适应选择最优特征**。这一设计思路与Kamal等 \[7\] 的DNN控制器"根据不同工况自适应输出控制命令"的理念一致。

### 5.3 训练策略

**损失函数**：Focal Loss（应对类别不均衡，sc_1ph/sc_3ph仅占0.6%）

$$\mathcal{L}_\text{focal} = -\sum_i \alpha_{y_i}(1-p_{y_i})^\gamma \log p_{y_i}, \quad \alpha_c \propto 1/\sqrt{n_c},\ \gamma=1.5 \tag{5.6}$$

**数据增强**：噪声注入+缩放（参照 \[7\] 中使用数据增强提高泛化性的做法）：

$$\mathbf{x}' = (\mathbf{x} + \epsilon) \cdot s,\quad \epsilon \sim \mathcal{N}(0, 0.02^2),\quad s \sim \mathcal{U}(0.90, 1.10) \tag{5.7}$$

附加随机时间偏移 $\pm 2$ 步（±0.1 ms），模拟 \[5\] 中描述的采样时刻抖动现象。

**训练历史**（实际在第6轮早停，参照 \[7\] 中DNN 30轮收敛，MSFFN仅需6轮，说明14通道特征质量极高）：

| Epoch | Loss | Val Acc | Val Macro F1 |
|-------|------|---------|--------------|
| 1 | 18.17 | 99.82% | 99.16% |
| 3 | 3.30 | 99.83% | **99.25%** ← 最优 |
| 6 | 1.78 | 99.82% | 99.24% |

## 6. AI控制方法：FAHC / PPO / DNN

### 6.1 故障感知分层控制器（FAHC）

#### 设计思路

FAHC的核心洞见来自DC母线能量守恒分析（参照 \[1\] 对DC母线功率流的建模，以及 \[6\] 对HPT储能容量的经济分析）：

$$\Delta E = \frac{1}{2}C_{dc}(V_{dc,\text{nom}}^2 - V_{dc,\text{ref,new}}^2) \tag{6.1}$$

$$\Delta E(800 \to 720\,\text{V}) = \frac{1}{2} \times 2200\,\mu\text{F} \times (800^2 - 720^2) = 134\,\text{J} \tag{6.2}$$

$$\Delta V_{dc} \approx \frac{\Delta E}{C_{dc} \cdot V_{dc,\text{nom}}} = \frac{134}{2200 \times 10^{-6} \times 800} \approx 76\,\text{V} \approx 0.095\,\text{pu} \tag{6.3}$$

对于边界失败场景（$V_{dc,\min} \in [0.65, 0.75]$ pu），0.095 pu的提升可使其越过LVRT阈值0.75 pu（Liu等 \[1\] 确定的VSC控制权威性下限）。

#### 四级策略表

| 策略 | 适用故障 | V_dc,ref | V₂_ref | I_lim | ΔE | 文献依据 |
|------|---------|---------|-------|-------|-----|---------|
| S0 | normal, igbt_oc_sh, igbt_oc_se | 800 V | 400 V | 3.0 pu | 0 J | \[1,3,9\] |
| S1 | cap_fault | 760 V | 400 V | 2.8 pu | 68 J | \[1,5\]（电容故障下降额运行）|
| S2 | sc_1ph | 740 V | 380 V | 2.8 pu | 101 J | \[3,10\]（单相故障控制策略）|
| S3 | sc_3ph, cascade | 720 V | 360 V | 2.5 pu | 134 J | \[6\]（严重故障能量分析）|

#### ET-PIRC启发的动态升级（新增）

受Lai等 \[2\] 提出的事件触发PI-重复控制器（ET-PIRC，eq.26–29）启发，引入动态策略升级机制。ET-PIRC中，当跟踪误差超过阈值时，动态分配系数 $K_{ET}$ 减小，使PI（快速响应）主导，RC（周期修正）让位：

$$K_{ET}(t) = \frac{B}{1 + \|e_d(t)\|}, \quad B=0.5 \quad [\text{Lai 2026, eq.29}] \tag{6.4}$$

在FAHC中，类比地监测DC误差和V₂误差（触发机制类比 \[2\] eq.28）：

$$e_{vdc}(t) = \frac{V_{dc,\text{ref}} - V_{dc}(t)}{V_{dc,\text{ref}}}, \quad e_{v2}(t) = \frac{V_{2,\text{ref}} - V_{2,\text{rms}}(t)}{V_{2,\text{ref}}} \tag{6.5}$$

$$|e_{vdc}| > A \cdot e_{\text{steady,vdc}} \quad \text{OR} \quad |e_{v2}| > A \cdot e_{\text{steady,v2}},\quad A=3.0 \tag{6.6}$$

其中 $A=3.0$ 参照 \[2\] 推荐的触发阈值因子范围（2–4）。触发后策略等级临时上调+1级（最多S3），2个基波周期（40 ms）内无重触发则回退。

### 6.2 PPO强化学习控制器

#### 奖励函数

以物理约束为中心的稠密奖励，直接对应 \[1,2\] 定义的LVRT判据：

$$r = 4.0 \cdot \mathbb{1}[\text{LVRT pass}] + 2.0 \cdot \frac{V_{2,\min}}{0.90} + 2.0 \cdot \frac{V_{dc,\min}}{0.75} - 10.0 \max(0,\, 0.75-V_{dc,\min})_{\text{\scriptsize[1]}} - \cdots \tag{6.7}$$

PPO的奖励设计参考了贾科等 \[10\] 中对VSC-HVDC故障穿越的优化目标（同时优化DC侧电压稳定与交流侧无功支撑），使PPO在失败场景中仍能获得梯度信号。

**PPO LVRT通过率（350场景）**：59.43%（低于规则FRT，根本原因：场景观测为场景级特征，缺乏 \[2\] 中ET-PIRC使用的实时逐采样误差信号）

### 6.3 DNN仿制控制器（历史方法）

DNN学习dq控制器的输入输出映射，思路与Kamal等 \[7\] 的TAB相移DNN完全一致（离线扫描→训练DNN→在线直接推理）：

$$[\hat{V}_{se,d},\, \hat{V}_{se,q},\, \hat{I}_{sh,d}] = f_\theta\!\left([V_1,V_2,V_{dc},P_1,Q_1,P_2,\text{mode}]\right) \tag{6.8}$$

结构：7→256→256→128→3，MSE损失，5000个稳态快照，MAE=0.0028 pu。  
**注意**：此方法在旧拓扑上训练，修正Δ-Y相位偏移后（D1，依据 \[2\]）需要重新训练，当前版本在HPT v2拓扑上通过率约0.3%。

### 6.4 参考条件网络（RCN）

RCN是FAHC的连续版本，参照 \[1\] 中DC母线控制理论，连续输出参考量偏置：

$$[\Delta V_{dc,\text{ref}},\, \Delta V_{2,\text{ref}},\, \Delta I_{\text{lim}}] = \text{RCN}_\theta(\mathbf{s}) \tag{6.9}$$

两阶段训练：离线阶段用物理估算（依据 \[1\] 的能量分析），在线阶段可用Simulink网格搜索的真实最优参考重新训练（类比 \[7\] 中DNN的离线数据采集方法）。

### 7.3 失败分析：硬件能量瓶颈

sc_3ph、sc_1ph、cap_fault三类故障的低通过率，根本原因是**DC侧储能不足**（Liu等 \[1\] 通过功率平衡方程给出了理论分析，Zheng等 \[6\] 给出了量化储能需求的系统级框架）：

$$E_{\text{stored}} = 704\,\text{J} \ll E_{\text{required}} \approx 2000\text{–}5000\,\text{J（三相短路典型需求）}\quad [\text{推算自}\,6]$$

三相短路时 $I_{2,\max}=3.44\,\text{pu} > 3.0\,\text{pu}$ 限制（Liu等 \[1\] 确认的过流判据），V₂跌至0.254 pu，**任何软件控制均无法克服这一物理约束**。这与贾科等 \[10,11\] 在柔直系统中发现的类似现象（硬件额定电流限制是故障穿越失败的根本原因）完全一致。

Zheng等 \[6\] 的分析表明，将DC侧储能从704 J升至 ≥2000 J（需要 $C_{dc} \approx 6250\,\mu\text{F}$ 或添加电池储能BESS）是使三相故障通过率超过50%的**唯一可行路径**。Zheng等 \[6\] 同时给出了BESS调度优化模型，为日前计划和实时能量管理提供了参考框架。

### 8.2 AI检测 vs AI控制的性能差距

MSFFN v2故障检测准确率99.86%，而FAHC控制LVRT通过率仅62%。差距来自：
1. **训练数据分布差异**（参照 \[7\] 中DNN在不同工况下的泛化性讨论）：检测模型训练于840个场景（5种控制模式），而控制评估在350个独立场景上
2. **硬件物理约束**（\[1,6\] 均明确指出）：约43%（150/350）的失败场景属于硬件储能不足

Lai等 \[2\] 实验中ET-PIRC使故障后THD从6.91%降至1.75%，证明控制改善空间仍存在；但对于严重短路（sc_3ph），如贾科等 \[10,11\] 所分析，控制改进必须与硬件升级相结合。
