# HPT 故障波形特征说明

仿真条件：dq 双闭环控制（Mode 2），故障触发时刻 t = 0.3 s，仿真总时长 0.5 s。  
LVRT 判定标准：V_dc ∈ [600 V, 1000 V]，I₂峰值 ≤ 1732 A（3 pu）。

---

## normal — 无故障基准

**LVRT: PASS**

| 信号 | 特征 |
|---|---|
| V_dc | 启动瞬态后稳定在 ~790 V，纹波 ±10 V（±1.3%） |
| V2_abc | 三相平衡正弦，峰值 ~300 V，无扰动 |
| I2_abc | 三相平衡，峰值约 500~800 A，稳定 |
| V1_abc | 10 kV 侧正常，含串联 VSC 叠加纹波 |

基准参考：所有其他故障与此对比判断异常幅度。

---

## igbt_oc_sh — IGBT 开路（并联变流器）

**LVRT: PASS**

| 信号 | 特征 |
|---|---|
| V_dc | t=0.3s 有小幅跌落，随后纹波振幅增大（峰峰值约翻倍），但始终 > 600 V |
| V2_abc | 故障后三相轻微不对称，幅值略有波动，整体保持 |
| I2_abc | 三相出现轻度不对称，峰值未超限 |
| V1_abc | 基本无变化（故障在 LV 侧变流器内部） |

**诊断特征**：V_dc 纹波增大是主要标志。并联 VSC 开路导致直流侧充放电能力下降，表现为直流电压调节能力变弱、波动加剧。

---

## igbt_oc_se — IGBT 开路（串联变流器）

**LVRT: PASS**

| 信号 | 特征 |
|---|---|
| V_dc | 故障后 V_dc 纹波幅度增大，但比 igbt_oc_sh 更小，保持在限值内 |
| V2_abc | 三相基本平衡，略有扰动 |
| I2_abc | 幅值变化比 igbt_oc_sh 更小，波形更对称 |
| V1_abc | 无明显变化 |

**诊断特征**：与 igbt_oc_sh 相似但程度更轻。串联变流器开路后注入电压能力下降，对直流母线影响相对间接。两者主要区分依据是 I₂ 不对称程度——igbt_oc_sh 不对称更明显。

---

## cap_fault — 直流电容故障（2200 µF → 680 µF）

**LVRT: FAIL**

| 信号 | 特征 |
|---|---|
| V_dc | **全程纹波显著增大**（即使在 t=0.3s 之前）；t=0.3s 后跌落至 ~500 V 以下，低于 600 V 限值 |
| V2_abc | 低压侧电压随 V_dc 振荡，含明显低频分量（100 Hz 纹波） |
| I2_abc | 电流波形出现明显低频调幅，峰值接近或超过限值 |
| V1_abc | 无明显变化 |

**诊断特征**：唯一一种在故障触发**之前**就已出现明显异常（V_dc 纹波增大）的故障。电容减小导致直流储能不足，调节带宽严重下降。100 Hz 纹波（工频二倍频）是电容退化的典型标志。

---

## sc_1ph — 单相接地短路（A 相）

**LVRT: PASS**

| 信号 | 特征 |
|---|---|
| V_dc | t=0.3s 有轻微跌落，快速恢复，始终高于 600 V |
| V2_abc | t=0.3s 后**三相明显不对称**：A 相幅值跌落，B/C 相受影响较小；故障持续约 0.15 s 后三相逐步恢复 |
| I2_abc | A 相电流出现尖峰，B/C 相轻微扰动；整体在 3 pu 限值内 |
| V1_abc | 10 kV 侧受影响极小（高阻抗隔离） |

**诊断特征**：V2 三相**不对称**是核心特征，故障相幅值跌落而其余两相基本保持，区别于三相对称跌落。

---

## sc_3ph — 三相短路

**LVRT: FAIL**

| 信号 | 特征 |
|---|---|
| V_dc | t=0.3s **急剧跌落至 ~500 V 以下**，跌破 600 V 限值，振荡明显；故障清除后缓慢恢复 |
| V2_abc | t=0.3s 三相**对称性塌陷**至接近零，故障期间严重畸变；故障清除后出现大幅振荡恢复过程 |
| I2_abc | 故障瞬间出现大幅电流尖峰，**超过 3 pu 限值**（红色虚线以上），持续振荡 |
| V1_abc | 10 kV 侧几乎不受影响 |

**诊断特征**：最严重的故障类型。V2 三相**同时对称跌落**（区别于单相不对称），V_dc 跌幅最大，I₂ 尖峰最高。dq 控制器无法在 LVRT 窗口内维持直流母线稳定。

---

## cascade — 级联故障

**LVRT: PASS**

| 信号 | 特征 |
|---|---|
| V_dc | t=0.3s 跌落但幅度介于 igbt_oc 和 sc_3ph 之间，最低值接近但未跌破 600 V |
| V2_abc | 三相出现不对称扰动，程度比单相短路更复杂，含多频率分量 |
| I2_abc | 多相电流同时出现扰动，幅值接近限值但未超出 |
| V1_abc | 轻微扰动，比纯短路类故障更明显 |

**诊断特征**：波形特征介于 IGBT 开路与短路之间，兼有直流侧调节能力下降（纹波增大）和交流侧不对称（多相扰动）两种现象叠加，是最难诊断的类型。

---

## 对比总结

| 故障 | LVRT | V_dc 跌落 | V2 对称性 | I₂ 超限 | 主要诊断信号 |
|---|:---:|---|---|:---:|---|
| normal | ✓ | 无 | 对称 | 否 | — |
| igbt_oc_sh | ✓ | 小（纹波增大） | 轻微不对称 | 否 | V_dc 纹波 |
| igbt_oc_se | ✓ | 极小 | 基本对称 | 否 | V_dc 纹波（更小） |
| cap_fault | ✗ | 大（故障前已有纹波） | 含低频调幅 | 否 | **故障前已有 100 Hz 纹波** |
| sc_1ph | ✓ | 小 | **不对称**（单相跌落） | 否 | V2 单相跌落 |
| sc_3ph | ✗ | **最大**（< 500 V） | **对称塌陷** | **是** | V2 三相塌陷 + I₂ 超限 |
| cascade | ✓ | 中等 | 多相复合扰动 | 否 | 多信号复合异常 |
