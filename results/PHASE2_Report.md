# 二期报告:多 HPT 配电网协同故障穿越——定量排除法与直流互联价值链

**日期**:2026-06-12　**阶段**:二期 A 阶段(W1–W7)计算工作闭环
**一期基础**:[FRT_Academic_Report.md](FRT_Academic_Report.md)(单机 9 种决策律谱系,残差 SAC m14-v2 = 96.3% 全 320)

---

## 摘要

本报告研究多台混合配电变压器(HPT,400 kVA,电力电子容量 0.3 pu)在配电网故障中的集群协同穿越。基于三层建模架构(开关级 EMT / 标定快速代理 / OpenDSS 配电网),在 IEEE 33 节点馈线 + 10 台 HPT、400 个系统级故障场景上,**先后定量排除了五条交流侧协同路径**(集群无功抬网压 ~0.01 pu;装置内无功-串联权衡 −0.3 pp;故障窗无功配额协同 +0.3 pp;直流回充排程为 3 ms 级不可见事件;FIDVR 恢复窗杠杆薄且被平凡策略捕获)——证明在该装置容量比下,**交流侧集群协同不存在有实质内容的控制问题**。据此将研究主线转向 **HPT 直流母线互联(簇内直流池)**:健康馈段装置经直流链路为凹陷馈段的串联补偿供能,使串联升压从单机直流预算钳制(~4.5%)解放至额定(~9.4%)。实测价值链:负荷穿越率 57.2%(无互联)→ 61.1%(互联+朴素分配,**硬件 +4.0 pp**)→ 65.8%(互联+可翻转优先分配,**分配智能再 +4.7 pp**);池在 68.7% 的场景被争用。进一步以逐簇精确枚举证明:**可翻转优先启发式即单步最优分配(差 0.0 pp)**,且时序/电机耦合维度对分配器不敏感——系统层不需要学习器。最终方案定型为分层结构:**装置层 = 一期残差 SAC(学习),系统层 = 直流池 + 解析最优分配器**。方法学结论:"智能该放在哪一层"是可量化的问题;本工作给出了装置层(学习,+14 pp 溢价)与系统层(解析,枚举即最优)的分界证据,及"杠杆先量化、学习器后进场"的纪律流程。

---

## 1. 引言与动机

一期工作(单机)的核心发现是:单交流口 HPT 的 FRT 性能极限由**共享直流母线的功率预算**决定——串联补偿(保护负荷的最有效手段)每 0.1 pu 注入抽取约 0.19 pu 等效直流预算,故单机串联升压被钳制在 ~4.5%。这自然引出系统级问题:**多台 HPT 能否通过协同突破单机极限?** 文献侧(见 [week4/PHASE2_PLAN.md](../week4/PHASE2_PLAN.md) 文献清单):多 HT 配电网协调存在但全部为稳态优化方法 [P1][P2];MARL 配电网电压控制成熟但全部在慢时间尺度 Volt-VAR [P4][P5];百 ms 故障尺度的多装置学习型协同为空白。

## 2. 三层建模方法学(全部经审计)

```
L3 网络层  OpenDSS IEEE-33(权威凹陷传播)     自检:minV 0.9038@18 + 网损 210.99 kW(经典值 210.98)
   ↕ 标定审计:线性灵敏度代理 V≈V0+S·q,随机注入对照误差 max 0.004 pu
L2 协同层  Python 快速代理 + 一期标定装置模型   (RL/评测零 OpenDSS 调用可选)
   ↕ 互证:EMT(一期开关级)vs OpenDSS 同分压器,LV 残压偏差 max 0.0005 pu
L1 装置层  一期 Simulink 开关级 HPT            抽查:m14-v2 在 0.035 pu 本地凹陷仍 PASS
```

- 装置模型 = 一期忠实标定常数(`Vdc_eq = 1 − 0.08·iq/max(0.3,V) − 1.9·se`,裕度 0.82,SE_GAIN=0.47);
- 深凹陷边界:本地残压 ≤0.02 且持续 >0.15 s 超 GB/T 零电压包络,装置失效属物理边界(已记录);
- 工程产物:`phase2/ieee33.dss`、`w1_testbed.py`、`hpt_interface.py`、`w23_*`(对照)。

## 3. 系统级场景与判据

- **场景**(`w3_scenarios.py`,种子化可复现):400 = 故障母线(2-33)× 类型{3/2/1 相}× 电阻(log 0.3-30 Ω)× PV 渗透{30/60/90%}× 负荷{0.7,1.0};**清除时间与深度耦合**(全网最低电压 <0.2/<0.5/其余 → 0.15/0.30/0.625 s,GB/T 包络逻辑);
- **凹陷传播是协同问题的物理根源**(W1 实测):同一故障下各 HPT 本地凹陷差可达 0.85 pu(fault@12:HPT14=0.054 vs HPT25=0.897);
- **判据**(W2 物理账后重构):主指标 = 负荷穿越率(严格 ≥0.9 / 容忍 ≥0.7,经串联补偿后的本机 LV 电压)+ 装置合规率;
- **电机/FIDVR 模型**(`w5_motor.py`):负荷 50% 电机,其中 40% 为压缩机型(失速后不可再加速,NERC 机制),V_stall=0.55,工业再加速 0.78,热切 4 s——模型可复现 3.8 s FIDVR 与 9~22% 电机热切。

## 4. 定量排除法地图(本报告的方法学主贡献之一)

| # | 候选协同路径 | 定量结论 | 出处 |
|---|---|---|---|
| 1 | 集群无功抬网压(故障窗) | 4×120 kvar 抬 0.001-0.013 pu(灵敏度 ~0.1 pu/Mvar) | W2 `hpt_interface.py` |
| 2 | 装置内 iq↔串联预算权衡 | −0.3 pp(直流占用项过小) | W3 双基线 |
| 3 | 故障窗无功配额协同 | 协调器 +0.3 pp;全员拉满 +0.7 pp 即天花板 | W4 SAC+OpenDSS 终评 |
| 4 | 直流回充排程(恢复窗) | 704 J 电容 3 ms 充满,馈线级不可见 | W5.0 分析解 |
| 5 | FIDVR 恢复窗无功排程 | 热切量不可动;FIDVR 时长可动但"恢复期保持注入"一行即捕获 | W5.1 电机模型 |

**纪律**:每条路径先用审计过的工具量化杠杆,再决定是否建学习器——W4 的教训(为 +0.3 pp 训练了一个协调器)之后全程贯彻。

## 5. 直流互联:必然性与价值链(主结果)

**结构**(ReC-HDT [P3] 路线,任务书直流端口形态):3 簇 [4,7,10]/[14,17,21]/[24,28,31,33],簇内直流池——预算约束从逐装置 `se_i ≤ (0.18−sag_i)/1.9` 变为簇和 `Σse_i ≤ Σ(0.18−sag_i)/1.9`(+装置额定 0.2)。健康簇员(V≈1, iq=0)各贡献 0.095 → 凹陷簇员串联可达额定 0.2(升压 9.4%)。

**价值链**(400 场景,OpenDSS 精确电压,`w6_dcpool.py`/`w7_alloc.py`):

| 方案 | 负荷穿越(严格) | 增量 | 含义 |
|---|:---:|:---:|---|
| solo(无直流链) | 57.2% | — | 一期装置独立运行 |
| 池 + 朴素分配(最深优先) | 61.1% | **+4.0 pp** | **硬件杠杆**(互联本身) |
| 池 + 可翻转优先启发式 | **65.8%** | **+4.7 pp** | **分配智能**(朴素分配把预算浪费在救不活的深凹陷上) |
| 池 + 逐簇精确枚举最优 | 65.8% | +0.0 pp | **启发式已是单步最优** |

- 池争用率 68.7%(分配决策普遍存在而非边角);
- 容忍档:86.5 → 88.1%;电机场景实例:fault@25 热切 9.0→4.5%;
- 时序/电机耦合维度:各分配器在 FIDVR 场景零差异 → **系统层无学习器空间**。

## 6. 最终方案(二期 A 阶段定型)

```
装置层(学习):一期 m14-v2 残差 SAC(MPC 先验 + 残差 + 纹波钳位)= 单机 96.3%
系统层(解析):簇内直流池 + 可翻转优先分配器(几十行,可证单步最优)
价值链:57.2% → 65.8%(+8.6 pp,逐项可溯源、可复现)
```

**方法学结论**:
1. **智能的层级放置是可量化问题**:装置层学习溢价 +14 pp(一期 96.3 vs 最强固定律 64.1 的换算域),系统层枚举即最优(学习溢价 0.0 pp)——"学习放装置层、解析放系统层"在本系统是被证明而非被假设的;
2. **杠杆先量化、学习器后进场**:五次排除合计避免了至少五轮无效的 MARL 开发;
3. **评测基础设施与模型同样需要审计**(一期标定泄漏、二期代理/EMT 互证 0.0005 pu 的传统延续)。

## 7. 诚实局限

1. **准静态近似**:故障窗/恢复窗以快照序列近似,无机电暂态;相量近似的凹陷幅值已对照 EMT(0.0005 pu),但相位/暂态过程未覆盖;
2. **三相塌均值**:不对称故障的逐相凹陷与逐相串联补偿未展开(场景 70% 为不对称,逐相评测可能改变负荷穿越的绝对值,但排除法结论依赖的是策略间**差值**,敏感性较低);
3. **电机参数为文献典型值**(失速/再加速阈值、堵转倍数),未对标实测;
4. **直流链路容量假设无限**(簇内);限容敏感性与链路损耗待 B 阶段;
5. **池预算模型为功率平衡等效**(继承一期 1.9 常数),直流互联后的实际换流器间动态未在开关级复核——B 阶段应在 Simulink 搭双机直流互联做一次 L1 抽查;
6. 分配器最优性证明限于本判据结构(阈值翻转型)与小簇(≤4);其他价值函数/大簇下枚举复杂度与最优性需重检。

## 8. 后续(B 阶段候选)

1. **L1 复核**:Simulink 双 HPT 直流互联模型,验证池预算模型与换流器间动态(最高优先);
2. **逐相评测升级**(不对称凹陷 + 3×单相串联的逐相分配);
3. 链路容量/损耗敏感性 + 簇拓扑优化(选址与分簇,衔接 [P2]);
4. 微网孤岛形态(任务书);装置层多端口扩展(直流口作为第五端口进入一期模型)。
