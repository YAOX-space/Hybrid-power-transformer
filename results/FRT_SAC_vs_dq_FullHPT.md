## 方案(最终)

- **SAC**:**4 专家**(sym-LVRT / asym-LVRT / sym-HVRT / asym-HVRT,各 SAC 256³,**忠实 ODE** 训练)+ **Mode-12 物理门控在线路由**(控制器实时测正/负序自动选专家,权重 `coder.load` 内嵌、按训练步长 2 ms 降频推理,零人工干预);
- **dq 传统**:SRF-PLL + dq 电流环 + Vdc 外环 + GB/T 无功 droop `1.5(0.9−V)` + 比例串联支撑;
- 两控制器共用同一底层 VSC 与判据,同平台对比。

## 基线公平性检验(报告 §4.9,32 场景子集)

dq 基线的串联律为自设,按文献重构变体后同台:

| 基线 | 全 32 |
|------|:---:|
| dq-legacy(自设串联律) | 21.9% |
| dq-贾科式(串联随 Vdc 降额) | 50.0% |
| dq-宋幸式(FRT 期串联置零,无储能 HPT 文献默认) | 53.1% |
| dq-宋幸式 + 0.27 限幅(回灌 RL 两大发现的最强固定律) | 65.6% |
| **SAC 4 专家(当前权重)** | **81.2%** |

→ 旧基线确实自伤;RL 洞察可部分回灌给固定律(+43.7pp);**SAC 净优势 +15.6pp 仍显著**(逐工况自适应无功幅度 + 不对称平滑注入是固定律学不来的)。

## 机理(实测)

- **"深对称跌落 Vdc 必塌"被推翻**:无串联时残压 0.2 的深跌 Vdc 也稳在 0.93+;dq 崩溃是**满额串联升压自伤**(升压 0.2 → Vdc 0.60),非拓扑硬限;
- **SAC 学到的最优结构**:满额注无功(iq≈0.27 顶格不超)+ 克制串联(|mse|≲0.07)→ 深跌 Vdc 稳 0.81–0.95;
- **sim-to-real 是主要矛盾**:乐观 ODE 训练 → 部署即崩(~19%);用开关级扫描数据标定 ODE 直流模型(误差 ≤0.02)后同一管线 → 90%。

## 诚实的局限

1. **HVRT 1.3 pu 深骤升 SAC 落后 dq**(75.0 vs 81.2):吸无功深度不足(−0.14 vs 需 −0.30),可定向修复;
2. 残留失败 32/320:除 HVRT 20 例外,sym3ph 深跌 connect 边界 6 例、浅跌过注 5 例;
3. 不对称残压深度在 Δ-Yg 下不可达(1ph_g 三档实为同一工况),有效场景多样性低于名义;
4. 模型非真机:单口、线性变压器、未硬件对标;忠实 ODE 标定为模型特定。

## 结论

在完整 HPT、开关级、GB/T 全 320 场景、在线门控零人工干预下:**SAC 90.0% vs dq 32.8%(2.7×);对"被 RL 教过"的最强固定律仍净胜 15.6 pp**。优势本质:RL 发现并执行了"撑电压 vs 保直流"的逐工况最优权衡——固定增益控制律在结构上无法表达这件事。
