## 1. 正常运行（sc_id=0）

### 发生了什么
无外部故障，仅有负荷波动（P=200–400 kW，Q=0–160 kVAR 随机）。

### 各策略行为
| 策略 | 行为逻辑 |
|------|---------|
| **规则FRT** | m≈0.045（最小注入），V₂跌则线性放大m |
| **dq双环** | PI维持Vdc=800V，小幅SPWM维持V₂ |
| **FAHC** | MSFFN检测为class=0(normal)→策略S0→等同dq |
| **PPO** | 输出接近零偏置动作 |

### 效果对比
```
通过率：全部 100/50 = 100%
Vdc_min：规则=0.917pu  dq=0.917pu  FAHC=0.917pu  PPO=0.913pu
I2_max ：规则=1.38pu   dq=1.38pu   FAHC=1.38pu   PPO=1.38pu
```

**结论**：正常工况下四种方法效果完全一致，无显著差异。MSFFN识别准确（F1=0.9997），策略切换开销可忽略。

## 2. IGBT开路——并联侧 VSC_sh（sc_id=1）

### 物理机制
VSC_sh的某个IGBT断路 → 三相桥变为不对称 → DC母线充电能力下降 → Vdc缓慢跌落 → 若Vdc < 600V（0.75pu）则LVRT失败。

### 各策略行为
| 策略 | 行为逻辑 | 调制指数m的变化 |
|------|---------|--------------|
| **规则FRT** | 仅凭Vdc跌落触发m增大，无故障感知 | 0.045 → 逐渐上升 |
| **dq双环** | PI误差信号放大，m自动跟随 | 0.68±0.08（自动调节）|
| **FAHC** | 检测class=1→策略S0→与dq完全相同 | 同dq |
| **PPO** | 学到了轻度提升能量偏置，m略高 | 比dq稍高 |

### 效果对比
```
通过率：规则=88%  dq=88%  FAHC=88%  PPO=90%
失败模式：全部为 Vdc_min < 0.75pu（均为6个边界场景）
Vdc_min均值：规则=0.794pu  dq=0.794pu  FAHC=0.794pu  PPO=0.790pu

6个失败场景的Vdc_min分布：
  最严重：Vdc_min≈0.74pu（仅差0.01pu就能通过）
```

**结论**：四种策略差距极小。失败的6个场景Vdc跌幅已超出软件调节能力。PPO的90%（+1场景）源于其对"能量偏置"参数的微调，但优势不稳定。

## 3. IGBT开路——串联侧 VSC_se（sc_id=2）

### 物理机制
VSC_se的某个IGBT断路 → 该相串联注入失效 → V₂电压偏低，有轻度跌落 → 但DC母线维持良好 → 通常可以穿越。

### 各策略行为
| 策略 | 行为逻辑 |
|------|---------|
| **规则FRT** | 检测到V₂跌落 → 加大m补偿 |
| **dq双环** | DC环稳定，电压环自动补偿V₂ |
| **FAHC** | MSFFN准确识别（F1=1.000）→ S0策略 → 与dq相同 |
| **PPO** | 轻微动作偏置 |

### 效果对比
```
通过率：全部 50/50 = 100%
V2_min均值（二次侧跌落）：
  规则=0.824pu  dq=0.824pu  FAHC=0.825pu  PPO=0.825pu
V2恢复时间：~2.3ms（所有方法相同）
```

**结论**：该故障程度较轻，所有策略均可处理。V₂跌至约0.82pu后在2.3ms内恢复，远优于100ms限制。MSFFN对此类故障识别率达100%，为FAHC提供了精确的故障感知。

## 4. DC电容退化（sc_id=3）

### 物理机制
电容容值降至标称值50%（1100μF）→ 储能从704J降至**352J** → 同样的功率冲击导致Vdc跌幅加倍 → 大量场景Vdc < 0.75pu。

### 各策略行为
| 策略 | 行为逻辑 | 对应的参考电压 |
|------|---------|-------------|
| **规则FRT** | 无感知，仅靠Vdc跌落触发m增大 | Vdc_ref=800V（固定） |
| **dq双环** | PI强力追踪800V → 消耗剩余储能更快 | Vdc_ref=800V（固定） |
| **FAHC-S1** | 识别cap_fault → **降低Vdc_ref至760V** → 节省68J能量 | Vdc_ref=**760V** |
| **PPO** | 输出偏置，但训练轮数不足 | 小幅调整 |

### 效果对比
```
通过率：规则=20%  dq=20%  FAHC=20%  PPO=20%
Vdc_min均值：规则=0.679pu  dq=0.679pu  FAHC=0.680pu  PPO=0.670pu

失败场景中 Vdc_min 分布：
  [0.55, 0.75)：30个场景（轻度不足）
  [0.40, 0.55)：10个场景（严重不足）
```

**关键发现**：FAHC的S1策略（降压至760V，节省68J）**理论上可改善部分边界场景**，但实测效果与传统方法相同（均20%）。原因：退化后储能352J仍然远低于故障期间所需能量（~600–1000J），68J的节省量对大多数失败场景无实质帮助。

**结论**：这是一个纯粹的**硬件储能瓶颈**，软件策略均无效。需要增大DC储能（≥2000J）才能根本改善。

## 5. 单相短路（sc_id=4）

### 物理机制
某相接地 → 不对称电压跌落 → 一次侧I₁急增 → DC母线通过VSC_sh快速放电 → Vdc跌落是主要失败原因。

### 各策略行为

**规则FRT**（失败模式分析）：
```
仅凭V₂跌落调节串联VSC的m
→ m增大后反而从DC抽取更多能量
→ 加速Vdc跌落
→ 陷入"越补越空"的恶性循环
```

**dq双环**（明显改善）：
```
外环PI精确维持Vdc=800V
→ 控制VSC_sh的充放电时序
→ 在短路瞬间快速提升m_sh，阻止Vdc跌落
→ 保持Vdc在 >0.75pu 阈值
```

**FAHC-S2**（与dq相同效果）：
```
MSFFN识别sc_1ph（F1=0.987）
→ 分配策略S2（Vdc_ref=740V, I_lim=2.8pu）
→ 降低Vdc_ref → 节省101J
→ 但本质上仍依赖dq控制底层
```

### 效果对比
```
通过率：规则=16%  dq=26%  FAHC=26%  PPO=16%

dq比规则好在哪（5个改善场景的典型数据）：
  场景run003: 规则Vdc_min=0.540pu(FAIL) → dq=0.765pu(PASS)  改善+0.225pu
  场景run014: 规则Vdc_min=0.736pu(FAIL) → dq=0.837pu(PASS)  改善+0.100pu
  场景run022: 规则Vdc_min=0.612pu(FAIL) → dq=0.826pu(PASS)  改善+0.214pu

Vdc_min均值：规则=0.619pu  dq=0.707pu（+0.088pu）  FAHC=0.707pu  PPO=0.618pu

PPO为何没改善：
  状态观测仅包含场景级特征（负荷、故障时刻）
  无法感知Vdc的实时变化速率
  → 训练轮数不足，未学到有效策略
```

**结论**：**dq双环的闭环反馈是关键**，使Vdc_min平均提升0.088pu，将5个边界场景从失败拉入成功。FAHC通过正确识别故障类型并激活S2策略取得了与dq相同的提升（也是因为底层仍用dq控制逻辑）。规则FRT和PPO均无法捕捉到Vdc的实时动态而失效。

## 6. 三相短路（sc_id=5）

### 物理机制
三相同时接地 → 最严重短路 → V₂跌至0.25pu左右 → I₂冲击高达3.4pu（超过3.0pu限值） → DC能量在百毫秒内耗尽。

### 各策略行为
| 策略 | 行为逻辑 | 核心动作 |
|------|---------|---------|
| **规则FRT** | V₂≈0→m设为最大值0.24 → 强行维持注入 | 最大调制 |
| **dq双环** | PI强力追踪Vdc=800V → 拼命充电 | 全力补充DC |
| **FAHC-S3** | 识别sc_3ph → **Vdc_ref降至720V，I_lim=2.5pu** → 节能134J | 主动降压限流 |
| **PPO** | 策略不稳定（仅10轮训练） | 随机性大 |

### 效果对比
```
通过率：规则=0%  dq=14%  FAHC=14%  PPO=2%

规则为何0%：
  强行最大调制消耗DC → Vdc快速跌破0.75pu
  I2_max=2.586pu（未超3pu，但Vdc先垮）
  Vdc_min均值仅0.572pu

dq为何好：
  PI精确控制 → 在Vdc跌落前及时减小充电功率
  7个成功场景的Vdc_min均在[0.751, 0.810]pu
  Vdc_min均值提升至0.615pu（+0.043pu vs规则）

FAHC为何与dq相同：
  S3策略降低Vdc参考至720V → 节省134J
  但在真正的三相短路中，故障持续期间能量需求>>134J
  改善幅度与dq相当，无额外收益

PPO（2%）为何远差于dq（14%）：
  三相短路需要极快速的响应（<2ms内决策）
  PPO的状态观测无法感知实时Vdc跌落速率
  训练轮数不足（10轮），探索空间远未覆盖极端场景
```

**结论**：三相短路是本系统**最严峻的硬件约束**场景。Vdc_min均值仅0.57–0.62pu，储能704J与所需2000–5000J相差3–7倍。dq和FAHC的14%通过率来自7个**短路阻抗相对较大**（R_f=0.05–0.1Ω）的"温和"三相短路场景，其余43个场景任何软件策略均无法挽救。

## 7. 连锁故障（sc_id=6）——AI策略的负面案例

### 物理机制
先单相故障（持续约0.05s）→ 再三相故障 → 两阶段冲击叠加，但系统有0.05s的"缓冲窗口"可以提前准备。

### 各策略行为
| 策略 | 行为逻辑 |
|------|---------|
| **规则FRT** | 第一阶段单相时轻度响应，第二阶段三相时激活保护 → **靠系统自然缓冲穿越** |
| **dq双环** | 双环PI平稳渡过两个阶段 → **100%通过** |
| **FAHC-S3** | MSFFN识别"cascade"→ 分配**最激进的S3策略**（Vdc_ref=720V, I_lim=2.5pu）→ 刻意降低Vdc_ref **反而让7个边界场景失败** |
| **PPO** | 轻微偏置，部分场景失控 → 88% |

### 效果对比（关键负面发现）
```
通过率：规则=100%  dq=100%  FAHC=86%  PPO=88%

FAHC 失败的7个场景分析：
  场景run001: dq Vdc_min=0.780（PASS）→ FAHC Vdc_min=0.744（FAIL）  跌差-0.036pu
  场景run004: dq Vdc_min=0.776（PASS）→ FAHC Vdc_min=0.744（FAIL）  跌差-0.032pu
  场景run016: dq Vdc_min=0.754（PASS）→ FAHC Vdc_min=0.731（FAIL）  跌差-0.023pu
  ...（共7个场景，均为 Vdc在0.75~0.79pu的边界场景）

原因诊断：
  1. S3策略将Vdc_ref降至720V
     → 控制器目标变低 → 减少充电功率
     → 对于Vdc本来就在0.75~0.79pu附近的场景
     → 少充的那些能量恰好让Vdc跌破0.75pu门槛
  
  2. 连锁故障实际上不需要激进的能量节省
     → 它的Vdc_min=0.819pu（均值），远高于0.75pu阈值
     → 传统dq以800V追踪反而更"安全"
```

**结论**：这是一个典型的**AI过度介入**负面案例。FAHC把连锁故障当作"严重故障"（因为sc_3ph通过率14%很低），分配了S3能量节省策略，但连锁故障本来就能100%通过，强行降Vdc_ref反而破坏了边界场景的稳定性。

**改进方向**：FAHC策略表需要区分"cascade需要S0/S1"而非S3，或者引入ET-PIRC的动态升级机制，只在Vdc实际跌落时才触发策略升级，而非仅凭故障分类。

## 综合对比分析

```
┌────────────────────────────────────────────────────────────────┐
│  分类                │  机制              │  优缺点             │
```

### 各故障类型的最优策略

| 故障类别 | 最优策略 | 为什么 |
|---------|---------|-------|

| igbt_oc_sh | PPO略好（90%） | 微小的能量偏置有效 |

### FAHC策略表的修正建议

基于以上分析，当前策略表存在问题：

| 当前 | 问题 | 建议修正 |
|------|------|---------|

```

```

## 核心结论

1. **AI故障感知有价值，但策略分配是关键**：MSFFN识别准确率99.86%，感知环节本身没有问题。问题在于把cascade映射到过激的S3策略，需要根据实际仿真数据重新调校策略表。

2. **dq双环是当前最稳健的基准**：64%的通过率在硬件约束下已接近软件能力上限，对sc_1ph（26% vs 规则16%）和sc_3ph（14% vs 规则0%）有实质改善，且对cascade不会造成退化。

3. **硬件储能是根本瓶颈**：cap_fault（20%）和sc_3ph（14%）的低通过率，无论传统还是AI方法均无法突破。DC储能从704J升至≥2000J是唯一出路。

4. **PPO训练严重不足**：10轮训练无法覆盖故障场景的复杂状态空间，在sc_1ph（16%）和sc_3ph（2%）上明显劣于dq，在cascade（88%）上也比传统方法差。
