## 1. 题目与定位

**多混合配电变压器在配电网故障电压凹陷传播中的协同穿越控制**

文献空白(三块拼图的交集,2026-06 检索确认):
- 多 HT 配电网协调存在但全是**稳态优化方法**(牛津组 SLP 协调 [P1]、最优配置 [P2]、HDT 直流互联暂降补偿 [P3]);
- MARL 配电网电压控制成熟但全在**慢时间尺度 Volt-VAR**(MAPDN 基准 [P4]、MACSAC [P5]、PV 集群 MADRL [P6]);
- **没有人做"故障穿越时间尺度(百 ms)的多装置学习型协同"**。

我们的独有筹码(一期全部复用):开关级单机模型、忠实代理标定方法学、决策律谱系(固定律/MPC/RL/混合 m13)、统一口径评测体系。

## 2. 场景定义(新场景矩阵)

```
网络:    IEEE 33 节点(主)/ CIGRE MV(泛化测试)
装置:    N = 2-4 台 HPT,布点为实验变量(参考 [P2] 的最优配置作对照布点)
渗透:    PV 渗透率 {30%, 60%, 90%},负荷随机化(沿用一期种子化方法)
故障:    故障母线位置 × 故障类型(沿用 GB/T 四型)× 残压深度 × 持续时间
          → 凹陷沿馈线传播,各 HPT 看到不同深度/相位的凹陷(这是协同的根源)
规模:    目标 ~500 系统级场景(分层抽样子集 ~48 用于快速迭代,沿用一期方法)
```

**判据升级(装置级 → 系统级,2026-06-12 按 W2 发现重构)**:

> **W2 物理账(诚实约束)**:4×120 kvar 对 3.7 MW 馈线深故障的抬压能力仅 0.001~0.013 pu——"协同抬网压"在原容量比下空间极小。重构决策:① 指标改以**负荷穿越与装置合规**为主、电压支撑为辅;② **装置加密至 8~12 台**(2~4 Mvar,支撑效应进入可感区间)。

- **主指标:全网 HPT 负荷穿越率**(每台 HPT 经串联补偿保住自己 LV 负荷的比例)+ **装置合规率**(每台五判据);
- **协同维度**(由此重新定义):故障期**直流预算分配**(谁的 Vdc 裕度用于撑邻居)、**恢复期无功排程**(故障清除后的电压恢复窗口)、限流额度的全网调度;
- 辅指标:凹陷传播(受影响节点数/最低电压/恢复时间)、总无功出力、PV 削减量;
- 协同增益 = 协同策略 vs 各自为政(m14-v2 独立运行)的差值——**核心论点指标**。
- **装置层深度缺口**:网络故障下本地凹陷深至 0.05 pu(一期下限 0.2)——按"先考后补"处理(W2 抽查 m14-v2 @ 0.05-0.15,不及格再扩场景重训)。

## 3. 建模架构(三层,忠实代理方法学升级到网络级)

```
L3 网络层   OpenDSS(三相不平衡潮流/动态模式)── 凹陷传播的权威仿真
                │ 共仿真接口:opendssdirect.py(Python 进程内,毫秒级步进)
L2 协同层   Python 训练环境:网络快速代理(标定自 OpenDSS)+ N 台装置代理(一期忠实 ODE)
                │ 标定流程 = 一期方法学的网络级版本:OpenDSS 扫描 → 代理参数拟合 → 平衡点对照
L1 装置层   现有 Simulink 开关级 HPT(抽查验证:协同命令下单机行为的权威复核)
```

关键设计:
- **训练在 L2**(快),**评判在 L3**(OpenDSS 全量)+ **L1 抽查**(代表性场景的开关级复核)——一期"训练-验证分离"的三层版;
- 一期教训直接预防:标定显式声明参照、代理的每个通道(包括测量纹波等效)用扫描数据标定、判据口径全程统一;
- OpenDSS 动态模式做故障窗仿真;HPT 在 OpenDSS 中以受控电流源/PQ 元件接口,死区/限幅按一期实测特性。

## 3.5 方向修正(2026-06-12,W2-W5 五次量化排除后敲定)★

W2-W5 用审计工具链定量排除了五个交流侧协同杠杆(抬网压 0.01pu / 装置内权衡 −0.3pp / 故障窗 Q 配额 +0.3pp / 直流回充 3ms 事件 / FIDVR 恢复窗薄且被平凡策略捕获)。**结论:120 kvar 级装置对 MW 馈线,交流侧集群协同无实质控制问题。**

**二期主线改为:HPT 直流母线互联(ReC-HDT [P3] 路线,任务书直流端口形态)下的集群能量路由协同。**
- 物理保证非空:一期证明的"单口 Vdc 预算"硬约束变成协同资源——健康馈段 HPT 经直流链路给凹陷馈段的串联补偿供能,绕开交流网;
- 串联升压从预算钳制 ~4.5% 解放到额定 ~9.4%,负荷保护带与电机失速拯救带均扩 ~2.2×;
- 集群拓扑:3 簇 [4,7,10] / [14,17,21] / [24,28,31,33],簇内直流池(预算共享),链路容量为约束;
- 协同决策:深故障打击整簇时池预算不足 → **簇内分配给谁**是真实的多体优化/学习问题;
- 叙事闭环:一期发现约束 → 二期证明交流侧无解(排除法地图,作论文引言)→ 直流互联是必然解。

## 4. 研究方法(两阶段)

**阶段 A:分层单协调器(出第一篇论文)**
- 单机层:**m14-v2 残差 SAC(冻结,一期最终方案,全 320 = 96.3%)**;协调器动作设计天然契合——先验的约束参数(无功配额、Vdc 裕度目标 0.82、串联预算)正是系统层该调度的慢变量;
- 系统层:单个 SAC 协调器,观测=各 HPT 本地量+网络量测(电压相量、凹陷深度分布),动作=各 HPT 的协调参考(无功配额、串联使能、直流裕度目标);
- 对照组(照搬一期谱系方法学):无协调(各自 m13)/ 集中 OPF-MPC(网络级在线优化)/ 协调器 SAC——三方同台;
- 关键科学问题:协同增益有多大?在哪类场景(深凹陷/弱网/高渗透)增益最大?

**阶段 B:MARL 分布式(第二篇/扩展)**
- MACSAC [P5](week2 已有论文,约束式多智能体 SAC)做分布式执行,通信约束现实化;
- 与阶段 A 的集中协调器对比:性能损失 vs 通信/单点失效鲁棒性。

## 6. 风险与缓解

1. **OpenDSS 动态模式对电力电子装置的表达力有限** → 装置动态封装在代理/接口模型中(OpenDSS 只管网络),临界行为靠 L1 Simulink 抽查兜底;
2. **网络代理标定误差**(一期已两次踩坑) → 标定清单制:每个物理通道列出、扫描、对照,留 §"代理忠实度审计"章节;
3. **协调器动作空间设计**(给参考 vs 给指令) → 沿用一期分层原则:协调器只动慢变量(配额/目标),单机 m13 保命权不上交;
4. **凹陷传播在相量域的保真度**(百 ms 尺度相量近似) → W2 用 Simulink 小网络(2-3 节点 + 2 HPT)做一次 EMT-vs-OpenDSS 凹陷传播对照,定标可信边界。
