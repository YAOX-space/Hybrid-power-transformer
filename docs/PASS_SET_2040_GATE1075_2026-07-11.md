## Interpretation

The original 72 traditional-only cases were not primarily an HVRT expert weight problem. The
dominant failure was late online routing: shallow HVRT events briefly used the `sym` SAC expert,
which produced positive reactive current and triggered the frt-v2 HVRT wrong-sign reactive FAIL.

Lowering the HVRT routing threshold to `1.075` switches shallow over-voltage events to the HVRT SAC
experts before the wrong-sign sample is produced. This closes the traditional pass-set gap while
also increasing total 2040 proxy pass count from `1636` to `1718`.

The r2 targeted HVRT retraining run was not selected: it improved the direct expert target metric,
but full routed pass-set evaluation showed the current HVRT weights plus earlier gate performed best.
