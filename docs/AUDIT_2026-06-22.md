## B. 经核对**并非缺陷**（避免误改）
- **iq→kvar 换算正确**：`iq_to_kvar = iq·HPT_KVA = iq·400`，故 iq=0.3 pu → **120 kvar = PE 满额**（用户担心的「≈36 kvar / 再乘 0.3」**当前代码不存在**）。仍建立 `pu.py` 单一事实源 + 自动测试锁死，防回归。
- 网络层 `solve_fixed_point` 的不收敛场景**已单独记录**（`info['nonconverged']`、aggregate 的 `convergence_pct`），未静默从分母删除——但需确保所有实验脚本都如实分母报告（已核对 run_exp_B/run_baselines 是）。
