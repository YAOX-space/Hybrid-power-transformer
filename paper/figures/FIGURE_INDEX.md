## Evidence Notes

- Quantitative pass/beat counts are read from `paper/evidence` and `lab/results` when present.
- `fig06_switchlevel_waveform_comparison` is metric-derived from switch-level summary rows, not a raw timeseries export.
- `fig09_proxy_alignment` separates calibration-near fit from broader holdout mismatch, so proxy-only improvements remain hypotheses.
- `fig11` is the final one-actor `3 x 3` switch-level pass matrix: family SAC r6 passes `8/9`, while strong dq passes `4/9`. The pass set is non-monotonic because the isolated `0.625 pu / 240 ms` cell fails the active DC-link gate, so the figure is not presented as a smooth depth-duration boundary.
- `fig12` uses the recorded r6 SAC episode-return and proxy-violation traces; it is not a reconstructed monotonic curve.
- `fig13` overlays raw 2-ms switch-level traces for the `0.50 pu / 200 ms` DQ-fail/SAC-pass boundary case, including LV RMS, Vdc, and all four modulation commands.
- Reproducibility metadata and source hashes for Figs. 11-13 are stored in `simulink_control_traces/fig_t2_a_deep_lvrt_r6_evidence_manifest.json`.
